# LanShare 🎓

> 一个装进教室里的 AI 教学小助手，让上课这件事轻松一点、聪明一点。

## 它是什么？

LanShare 是一个为真实课堂打造的教学平台。它最早只是一个在机房里给学生传文件的小工具，后来一路"进化"，长成了一个能陪老师走完整个学期的教学伙伴——从开学建课、日常上课、布置作业、组织考试，到期末整理各种教学材料，它都能搭把手。

最特别的是，它把 AI 深度融进了课堂的每个角落：AI 能帮你出题、批改作业、回答学生提问、归集错题、生成教案和各种教学表格……老师负责教学的温度，AI 负责重复劳动的苦差事。

## 它能做什么？

**给老师的：**

- 📚 **建课管课** — 班级、课程、学期、课表一站式管理，学生名单一键导入
- 📝 **作业与考试** — 布置、收取、批改全流程在线，AI 还能帮你出卷和批改
- 💬 **课堂互动** — 实时讨论区、随机分组、投票活动、私信沟通，课堂气氛拉满
- 🤖 **AI 助教** — 学生随时提问，AI 随时回答；老师也能让 AI 帮忙解析材料、优化文档
- 📊 **学情洞察** — 学习进度、错题归集、知识点掌握度，学生学得怎么样一目了然
- 📄 **教学材料** — 教案、考核计划表、教师评学表这些"期末大礼包"，AI 帮你生成、一键导出成规范的 Word 文档
- ⏰ **贴心提醒** — 监考提醒、待办日历、邮件通知，重要的事再也不会忘

**给学生的：**

- 🏠 一个属于自己班级的在线课堂，资料、作业、讨论都在一个地方
- 🌟 学习进度、阶段考试、成长称号，学习像闯关一样有反馈
- 🧭 职业发展路线图：做个性格测试，AI 帮你规划专业方向和成长路径
- ✍️ 课堂博客，记录和分享学习心得

## 什么场景适合用它？

- 🏫 **机房 / 局域网教学** — 在学校机房上课，需要发资料、收作业、组织讨论
- 👩‍🏫 **多班级教学** — 一个老师带好几个班、好几门课，需要一个统一的管理台
- 🤝 **想拥抱 AI 的教学团队** — 希望把 AI 出题、批改、答疑真正用进日常教学
- 🔒 **在意数据自主的学校** — 所有课堂数据、文件、学生提交都存在自己的服务器上，不依赖外部平台

## 大概的技术方向

不展开细节，简单说：后端是 Python（FastAPI），前端是轻量的网页界面，数据存在 PostgreSQL 数据库里，AI 能力通过独立服务对接 DeepSeek、火山方舟等国内大模型平台。整套系统既能跑在一台普通的教师电脑上，也能用 Docker 部署到云服务器，支撑一两百人同时在线上课。

## 怎么用？

三步走：

1. **准备环境** — 一台装了 Python 的电脑（Windows 或 Linux 都行），准备一个国内 AI 平台的 API Key（比如 DeepSeek）
2. **配置启动** — 填好配置文件，启动主服务和 AI 服务两个程序（想省事也可以用 Docker 一键起全套）
3. **开始上课** — 老师登录后台建班级、导名单、开课堂；学生用浏览器打开网址就能进教室，什么都不用装

> 详细的安装部署步骤请看 [DEVELOPMENT.md](DEVELOPMENT.md)（本地开发）和 [DOCKER_DEPLOYMENT.md](DOCKER_DEPLOYMENT.md)（服务器部署）。

启动之后：

- 老师入口：`http://你的地址:8000/teacher/login`
- 学生入口：`http://你的地址:8000/student/login`

把地址发给学生，一间在线教室就开张了。🎉

## 一句话总结

LanShare 想做的事很简单：**把老师从琐碎的事务里解放出来，把 AI 变成课堂里靠谱的第二位老师。**

祝上课愉快！✨
