# 三次握手

> 一部写给《计算机网络》课程的入门小说。
> 读完它不需要任何基础，但读完之后，你会知道每一次点开网页的背后，都有一场惊心动魄的旅行。

---

## 第一章 · 水晶头

林小满对大学的全部想象，在开学第三天的晚上十一点四十分碎掉了。

不是因为室友的呼噜，也不是因为食堂的菜价，而是因为她宿舍的网——断了。

明天早上八点，全校选课系统开放。热门课程手慢无，《计算机网络》这门课的授课老师是全院出名的"孟婆"，据说挂科率感人，但讲课是真的好，年年被抢爆。林小满已经把选课页面在浏览器里排练了十几遍，就等着明早拼手速。

结果现在，路由器上那颗代表外网的小灯，红得像是在嘲笑她。

她拔了插、插了拔，重启了三次路由器，甚至对着它吹了口气——都没用。室友们已经睡了，走廊尽头的值班室黑着灯。她抱着笔记本电脑在楼道里游荡，像个网络难民，最后在一楼活动室的门缝里看到了光。

活动室里坐着一个高个子男生，面前摊着一堆她看不懂的东西：一卷蓝色的线缆、一把奇怪的钳子、还有一个巴掌大的仪器，屏幕上的数字一闪一闪。

"同学，"林小满敲敲门，"你懂网络吗？我宿舍断网了。"

男生抬起头，推了推眼镜："哪个宿舍？"

"三楼，307。"

"哦，那你来对了。"他晃了晃手里的钳子，"三楼的问题我知道，主线被人踩坏了，我正在做新的。"

林小满凑近了看。他手里捏着一段网线，正把里面八根花花绿绿的细线捋直、排序，然后塞进一个透明的小塑料头里，再用钳子"咔哒"一声压紧。

"这是什么？"

"水晶头，RJ45。"男生把压好的线头插进那个小仪器，八个灯依次绿了一遍，"网线里有八根芯，橙白、橙、绿白、蓝、蓝白、绿、棕白、棕——顺序错一根，网就通不了。你们宿舍楼的网，追到最底下，就是靠这几根铜丝里跑的电信号。"

"就……这么原始？"林小满有点难以置信，"我以为网络是很玄的东西，看不见摸不着。"

"所有看不见摸不着的东西，最底下都有一层看得见摸得着的。"男生把新做好的网线卷起来，"这一层，教科书里叫**物理层**。信号在铜线里是电，在光纤里是光，在WiFi里是电磁波——形式随便换，本质都是把0和1从一个地方搬到另一个地方。"

他站起身，顺手把工具收进包里："我叫秦路，网络工程大三的，兼职管咱们这几栋楼的网。走吧，带你去接线，不然你明早抢不到孟婆的课。"

林小满跟在他身后爬楼梯，忽然问："你怎么知道我要抢孟婆的课？"

"这个点还醒着满楼找网的新生，"秦路头也不回，"不是抢课的，就是打游戏的。你看起来不像打游戏的。"

> **📌 知识便签 · 第一章**
> - **物理层**是网络分层结构的最底层，负责在物理介质（双绞线、光纤、无线电波）上传输原始比特流。
> - 常见的**双绞线**内有 8 根芯线，按 T568B 标准排序压入 **RJ45 水晶头**。
> - 无论上层应用多复杂，最终都会变成 0 和 1，在物理介质上以电、光或电磁波的形式传输。

## 第二章 · 风暴

第二天早上七点五十九分，林小满的手指悬在鼠标上，像短跑运动员等待发令枪。

八点整，她点下"选课"。

页面转了一圈，白了。

再刷新——"服务器繁忙，请稍后再试。"

三分钟后，新生群炸了。有人截图，有人哀嚎，有人已经开始编造阴谋论："肯定是教务处服务器是十年前的老爷机！""听说去年也崩了！"林小满盯着屏幕，忽然想起昨晚那个修网线的学长，抱着电脑就往一楼跑。

活动室没人。她又跑去了学校网络中心——一栋不起眼的小楼，机房的玻璃门里，秦路果然在，正站在一排闪着密集绿灯的黑色机柜前面，眉头拧成一团。

"选课系统崩了？"林小满隔着门喊。

"系统没崩。"秦路把门推开一条缝，"服务器好好的，负载都没满。是教学楼那边的网络出了问题——你自己看。"

他把一块监控屏转过来。屏幕上是一张网络拓扑图，教学楼区域的几个节点全部飘红，流量曲线像心电图猝死前的最后一搏，疯狂地顶在天花板上。

"这叫**广播风暴**。"秦路调出日志，"早上有个老师嫌教室网口不够用，自己带了个小交换机来，插的时候不小心把两个口用一根线连回了同一个网络——形成了一个环。"

"环怎么了？"

"你可以把交换机想象成一个包裹分拣员。"秦路抓过白板笔，在玻璃上画了三个方框，"每台电脑都有一个出厂就焊死的身份证号，叫 **MAC 地址**。分拣员记性很好，谁在哪个口，它记一张表，包裹来了照表转发。但如果它遇到一个不认识的地址，或者收到一个'所有人都要看'的广播包，它就会往除了来路之外的所有口都发一份。"

他在三个方框之间画了一个圈："现在网络里有个环。一个广播包发出去，绕着圈子转一圈又回来了，分拣员以为是新包裹，再发一遍。一传十，十传百，几毫秒之内，整个网络里全是同一个包的复制品，真正的数据反而挤不进去了——就像高速公路上所有车道都被同一辆车的克隆体占满。"

"所以大家不是抢不到课，是请求根本就没送到服务器？"

"聪明。"秦路一边说一边在键盘上敲了几行命令，"我现在把出问题的端口关掉……顺便，正规的交换机本来有一套叫**生成树协议**的机制专门防环路，会自动把环上多余的口堵住。那台自带的小交换机太便宜，没这功能。"

屏幕上，飘红的节点一个接一个恢复了绿色。流量曲线像退烧一样缓缓落下。

八点二十一分，选课系统恢复。林小满蹲在机房门口，用膝盖上的笔记本抢到了《计算机网络》的最后三个名额之一。

她合上电脑，长出一口气，忽然觉得这门课还没开始上，自己就已经预习了两章。

> **📌 知识便签 · 第二章**
> - **数据链路层**负责在同一个局域网内传输数据帧，核心设备是**交换机**。
> - **MAC 地址**是网卡的全球唯一硬件地址，共 48 位，通常写成 `A1:B2:C3:D4:E5:F6` 的形式。
> - 交换机通过自学习维护"MAC 地址 → 端口"映射表；遇到广播帧或未知地址会向所有端口泛洪。
> - 网络中出现**环路**会导致广播帧无限复制，形成**广播风暴**；**生成树协议（STP）**通过逻辑上阻断冗余链路来消除环路。

## 第三章 · 假的教务处

选课风波过去一周后，新生群里流传开一条消息：

> 【教务处通知】因选课系统故障，部分同学选课数据丢失，请点击以下链接重新验证学籍信息，逾期未验证将取消选课资格：jwc-verify.xxxx.com

链接后面跟着一长串参数，页面做得有模有样：校徽、红头、宋体字，连页脚的备案号都有。群里已经有十几个人回复"验证完了"。

林小满也点了进去。页面让她输入学号、密码、身份证号。她填到一半，忽然停住了。

有什么地方不对。

她盯着浏览器地址栏看了几秒——地址开头是 `http://`，前面没有那把小锁。而她登录真正的教务系统时，地址栏左边一直有一把灰色的小锁图标。

她截了图，发给了秦路，附了一句："这个是真的吗？"

秦路的回复十秒钟就到了，一连三条：

"假的。"
"别输密码。已经输了的赶紧改。"
"你怎么看出来的？"

"地址栏没有小锁。"

"很好，你已经超过百分之九十的用户了。"秦路发来一大段语音，背景音里他好像正在跑步，"那把小锁是 **HTTPS**，S 是 Secure。没有它，你和网站之间传的所有东西——包括密码——都是明文裸奔，路上任何一个节点都能看光。有了它，数据在出发前会被加密，中间人就算截到了，看到的也是乱码。"

"可是页面做得跟真的一模一样。"

"页面可以抄，域名抄不了。"秦路说，"真教务处的域名是 `jwc.你们学校.edu.cn`，这个假的是什么乱七八糟的商业域名。你在浏览器输入一个网址的时候，电脑其实不认识字母，它得先去问一个叫 **DNS** 的东西——你可以理解成全网的114查号台——把域名翻译成一串数字地址，也就是 **IP 地址**，然后才知道去哪找这台服务器。骗子注册一个长得像的域名，DNS 照样老老实实给它翻译，翻译系统本身没错，错的是你认错了名字。"

林小满把假链接举报到了辅导员那里。当晚，学校发了全员提醒，网络中心把那个域名加进了黑名单——用秦路的话说，"在学校的出口**防火墙**上给它上了户口，永久拒收"。

睡前，林小满看着浏览器地址栏那把小锁，忽然觉得它像一个沉默的保镖。以前她从来没有注意过它的存在，而它已经默默护送了她的密码几百次。

> **📌 知识便签 · 第三章**
> - **DNS（域名系统）**负责把人类可读的域名（如 `www.example.com`）解析为机器使用的 **IP 地址**。
> - **HTTP** 是明文传输的应用层协议；**HTTPS = HTTP + TLS 加密**，浏览器地址栏的锁形图标表示连接已加密且服务器身份经过证书验证。
> - **钓鱼网站**通常模仿真实页面骗取账号密码，鉴别要点：检查域名是否官方、是否使用 HTTPS、证书是否有效。
> - **防火墙**部署在网络边界，按规则放行或拦截流量，是网络安全的第一道闸门。

## 第四章 · 谁动了我的数据包

十月中旬，怪事再次降临三号宿舍楼。

这次不是断网。网是通的，甚至速度也不慢，但楼里接二连三有人游戏账号被盗、外卖平台被人下了陌生订单。受害者们唯一的共同点是：都连过楼下奶茶店的免费 WiFi——"甜甜屋-免费高速"。

秦路抱着笔记本电脑在奶茶店坐了一下午，回来的时候脸色阴沉。

"有人在做 **ARP 欺骗**。"他把电脑转向林小满。屏幕上是一个她看不懂的软件，密密麻麻滚动着一行行数据，"这软件叫抓包工具，能把网卡收到的每一个数据包摊开来看。你看这里——"

他指着其中一行："正常情况下，你的手机要上网，得先问一句：'网关在哪？'——网关就是局域网通往外面世界的大门。这个询问用的协议叫 **ARP**，它的机制特别天真：谁回答，就信谁，不核实身份。"

"然后有人冒充了大门？"

"对。攻击者在同一个 WiFi 里不停地喊：'我就是网关！把数据都给我！'于是所有人的流量都先流进他的电脑，他过一遍手、抄一遍明文密码，再转发给真网关——用户毫无感觉，网速只是慢了一点点。这叫**中间人攻击**。"

林小满起了一身鸡皮疙瘩："那……HTTPS 的数据他也能看？"

"看不了内容，这就是加密的价值。"秦路难得地笑了一下，"但很多小网站、老 App 还在用 HTTP，明文的账号密码就这么被捞走了。而且大部分人到处用同一套密码——偷到一把钥匙，等于偷到一整串。"

"能抓到他吗？"

"能。"秦路眼里闪着光，"他冒充网关的时候，暴露了自己的 MAC 地址。MAC 是可以伪造的，但他要收货，就必须用真实的端口。我在交换机上查这个 MAC 挂在哪个口——"他敲了几行命令，"——奶茶店里侧靠窗的那个网口。配合店里的监控，就知道那个位置这几天一直坐着谁。"

第二天，奶茶店监控拍到的常客——一个校外的"技术爱好者"——被警方带走了。他的电脑里存着四百多组明文账号密码。

网络中心随后在全校无线网上开启了防护：接入层交换机绑定了 IP 与 MAC 的对应关系，陌生设备再喊"我是网关"，交换机直接把包丢掉。

"这个事件给你上的课，"秦路总结，"比孟婆一学期讲的都直观——**永远不要在公共 WiFi 里裸奔，永远不要一套密码走天下。**"

> **📌 知识便签 · 第四章**
> - **ARP（地址解析协议）**用于在局域网内把 IP 地址解析成 MAC 地址；它没有身份验证机制，因此可被**ARP 欺骗**利用。
> - **中间人攻击（MITM）**：攻击者把自己插入通信双方之间，窃听或篡改数据。加密协议（HTTPS/TLS）能有效防止内容被窃取。
> - **网关**是局域网通往外部网络的出口设备（通常是路由器）。
> - 防御手段：交换机端口绑定 IP-MAC、动态 ARP 检测（DAI）、尽量使用 HTTPS、避免在公共 WiFi 处理敏感操作。

## 第五章 · 一封信的旅行

期中之后，林小满正式成了网络中心的学生助理——秦路推荐的，理由是"直觉好，胆子大，还没被带坏"。

值班的晚上大多很闲。某个安静的雨夜，林小满盯着监控屏上流淌的数据曲线，忽然问："秦路，你说我现在给我妈发一条'我想吃你做的红烧肉'，这句话是怎么跑到一千公里外她手机上的？"

秦路从泡面里抬起头，想了想，拉过白板。

"行，今晚给你讲个完整的。这句话的旅行，分五层。"

他画了五个叠在一起的方块，从上到下写：应用层、传输层、网络层、数据链路层、物理层。

"**第一站，应用层。**你的聊天软件把'我想吃红烧肉'打包成它自己的格式，就像把信纸装进信封，写好收件人。

**第二站，传输层。**这里的主角叫 **TCP**。它干三件事：第一，把长消息切成一段段编好号的小块；第二，在发送前先跟对面握手确认——这个待会儿细说；第三，盯着每一块的回执，丢了就重发。它保证你这句话**一个字都不会少、顺序一个都不会乱**地到达。

**第三站，网络层。**每一小块数据被贴上出发地和目的地的 **IP 地址**，成为一个独立的**数据包**。从这里开始，它进入广阔的互联网，一路上经过十几台**路由器**。每台路由器都像一个路口的交警，看一眼包裹上的目的地址，查一下自己的**路由表**，决定往哪个方向踢一脚。没有任何一台路由器知道全程路线——每台只负责'下一跳'，但千万次下一跳接力起来，包就到了。

**第四、五站，链路层和物理层。**咱们前面都见过了：在每一段具体的线路上，数据被装进帧、变成电信号或光信号，冲过铜线、光纤、基站，完成物理上的位移。"

"那握手是怎么回事？"

"哦，**三次握手**，TCP 的开场仪式。"秦路放下笔，"两台机器正式传数据之前，要先确认彼此都在线、都准备好了。你打电话是不是也这样？——你说'喂，听得到吗'，对面说'听到了，你能听到我吗'，你再说'能，说正事吧'。三句话，缺一不可：少了第一句，对面不知道你要通话；少了第二句，你不知道对面活着；少了第三句，对面不确定你收到了它的确认。三次，是建立一个'双方都确信对方能收发'的最小次数。"

"SYN，SYN-ACK，ACK。"林小满念出课本上的术语。

"对。从那以后，连接建立，数据开始流动。等这句'红烧肉'被你妈的手机组装还原、弹出通知，全程大概几十毫秒。"秦路把笔帽按回去，"几十毫秒里，几百台设备为你这七个字接力了一场跨越千里的马拉松——而你只觉得，嗖，发出去了。"

窗外雨声正密。林小满看着屏幕上安静流淌的流量曲线，忽然觉得那不是数据，是几万条同时出发的信，正各自奔赴天南海北。

她给妈妈发了那条消息。

三秒后，妈妈回复："好，周末回来做。"

> **📌 知识便签 · 第五章**
> - 网络体系采用**分层模型**：TCP/IP 五层结构为应用层、传输层、网络层、数据链路层、物理层，各层各司其职、逐层封装。
> - **TCP** 提供可靠传输：切分报文、编号、确认、超时重传、流量控制。
> - **三次握手**：客户端发 SYN → 服务器回 SYN+ACK → 客户端回 ACK，连接建立。
> - **路由器**工作在网络层，依据**路由表**逐跳（hop-by-hop）转发 IP 数据包，没有设备掌握全网完整路径。

## 第六章 · 洪水与堤坝

十二月，期末考试周之前，学校迎来了真正的大敌。

那天下午四点，教务系统、图书馆系统、正在进行的四级模拟考平台——同时瘫痪。监控大屏上，学校出口的入站流量在九十秒内暴涨了四十倍，红色告警铺满了整面墙。

"不是设备故障。"值班工程师的声音发紧，"是 **DDoS**——分布式拒绝服务攻击。"

林小满站在秦路身后，看着屏幕上跳动的数字。攻击的原理她这学期已经学过了，此刻却是第一次亲眼看见：成千上万个来自全国各地的 IP 地址，正以每秒几十万次的频率向学校服务器发起连接请求。每一个请求都伪装得像正常访问——服务器不得不接待每一位"访客"，为它们分配资源、等待后续数据。而这些访客占了座位就消失，永远不说下一句话。

"还记得三次握手吗？"秦路头也不回地敲着键盘，"攻击者只发第一句'喂'，服务器礼貌地回'听到了'，然后傻等第三句——等的这段时间，座位一直占着。几十万个'喂'同时涌进来，座位瞬间坐满，真正的学生反而挤不进门。这招叫 **SYN 洪泛**，专门滥用协议的善意。"

"能挡吗？"

"一台服务器挡不住洪水，但堤坝不止一道。"秦路调出防护平台，"第一道，出口设备开启 SYN 防护，代替服务器先应付那声'喂'，确认对方真会说第三句话，再放进来；第二道，联系运营商，在上游直接把攻击流量分流清洗——洪水还没到校门口就被引进了泄洪区；第三道，把明显异常的 IP 段临时拉黑。"

机房里键盘声密集如雨。四点四十分，流量曲线开始回落；五点过半，各系统陆续恢复。晚上，网警立了案——初步判断是有人对四级模拟考平台的服务商发起的商业报复攻击，学校只是被殃及的池鱼。

收拾东西下班的时候，林小满忽然说："我以前觉得网络就是个工具，坏了就修。现在觉得它更像一座城市——有道路，有邮局，有查号台，有城门，也有小偷和洪水。"

"所以才需要有人守城。"秦路把机房的灯关掉一半，绿色的指示灯在黑暗里明明灭灭，像整座城市的呼吸，"孟婆上课第一句话说什么，你还记得吗？"

林小满笑了："记得。'同学们，互联网是人类有史以来建造的最大的机器——而这门课，教你看懂它的图纸。'"

> **📌 知识便签 · 第六章**
> - **DoS（拒绝服务攻击）**通过耗尽目标资源使其无法服务正常用户；**DDoS** 是利用大量分布式主机（僵尸网络）同时发起的 DoS。
> - **SYN 洪泛攻击**滥用 TCP 三次握手：只发 SYN 不回 ACK，占满服务器的半连接队列。
> - 常见防御：SYN Cookie / SYN 代理、上游流量清洗、黑名单限流、内容分发网络（CDN）分担压力。
> - 网络安全的本质是攻防双方对协议理解深度的较量——**深入理解协议，是攻击者的起点，更是防御者的地基。**

## 尾声 · ACK

学期最后一天，《计算机网络》期末成绩公布。林小满考了全院第三。

她跑到网络中心报喜的时候，秦路正在收拾自己的工位——他保研了，去外地读研，下学期就走。桌上那把压线钳、那卷蓝色网线、那个八灯测线仪，被他推到林小满面前。

"传给你了。"他说，"三号楼的网，以后归你管。"

林小满抱着那堆工具，忽然不知道说什么。半年前那个在楼道里流浪的断网新生，现在能独立处理广播风暴了；而这一切的起点，只是一根被踩坏的网线。

秦路背上包，走到门口，忽然回头。

"哎，林小满。"

"嗯？"

"SYN。"他说。

林小满愣了一秒，然后笑出声。她太熟悉这个了——连接建立的第一步，一声试探的问候：*我在这里，你准备好了吗？*

"SYN-ACK。"她大声回答。*我收到了，我也在。*

秦路笑了，挥挥手，走进冬天傍晚的光里。走廊尽头传来他的最后一句：

"ACK——保持连接，别超时。"

机柜的绿灯在她身后安静地闪烁，像这座看不见的城市，永不熄灭的心跳。

**（全文完）**

## 📖 写给读者：这门课到底学什么

如果这个故事让你对某个瞬间产生过一点好奇——网线里怎么跑信号？交换机怎么认路？域名怎么变成地址？一条消息怎么跨越千里？攻击和防御到底在拼什么？——那么恭喜，《计算机网络》这门课，就是把这些好奇一个一个变成"原来如此"的地方。

故事里出现过的知识点，对应课程的主要章节：

| 故事情节 | 知识点 | 课程章节 |
|---|---|---|
| 水晶头与八根芯线 | 传输介质、比特流 | 物理层 |
| 选课夜的广播风暴 | 交换机、MAC 地址、环路与 STP | 数据链路层 |
| 假教务处钓鱼网站 | DNS 解析、HTTP/HTTPS、防火墙 | 应用层 / 网络安全 |
| 奶茶店 WiFi 盗号 | ARP 欺骗、中间人攻击 | 数据链路层 / 网络安全 |
| 一封信的旅行 | 分层模型、TCP 三次握手、IP 路由 | 传输层 / 网络层 |
| 考试周的洪水 | DDoS、SYN 洪泛与防御 | 网络安全 |

网络世界里没有魔法，只有协议。而协议，不过是机器之间的约定——就像人和人之间的信任一样，值得你花一个学期，认真读懂它。
