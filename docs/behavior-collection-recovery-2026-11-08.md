# 课堂计时采集恢复与签到证据基础（2026-11-08）

## 修复范围

现有采集器遇到除 408/429 外的 4xx 会永久 paused；online/focus/pageshow 不会解除暂停。后端部分无效 v2 心跳返回零增量，缺少采集质量证据。两者会把“没有成功采集”混入展示的零时长。

- 原批次内容、编号和账号范围保持不可变；未知提交、网络错误、超时、5xx/429 按退避与 Retry-After 重试原批次。
- 401 暂停新的 presence 测量，保留原批次。恢复同账号回执后重新起算，认证缺口不补算。
- 409 分成 identity_changed、内容冲突、过期、编号无效、服务端隔离/弃置等机器码。确定终止的批次本地隔离，后续合法队列继续；未知 409 保留探测。校验阶段 422 也明确标识终止。
- 切换账号后锁定旧页面、隔离旧队列、不再 beacon 重放。新页面按服务端渲染的账号独立恢复，bfcache 旧页面不能解除锁定。
- diagnostics 独立幂等上报；诊断、恢复、存储故障和缓冲区溢出均不增加课堂操作、活跃积分或学习秒数。旧批次原始内容留在原账号 sessionStorage 档案中，不能由新账号接收。
- 新表 `behavior_collection_observations` 与业务收件 apply 在同一事务记录有效区间样本数、拒绝数、原因、接收时间、观测范围及增量；重复回执不重复写入。状态型心跳不被当作完整的零秒观测。

## 独立统计口径

任课教师可读取 `GET /api/classrooms/{id}/activity-evidence?window_start=...&window_end=...`，限最近七天、最多24小时，时间以 Asia/Shanghai 解释。默认不返回原始登录 IP；显式 `include_login_ips=true` 仍须任课教师权限。返回 no-store。

每个在册/已确认重修学生分别返回：

1. `login`：平台成功登录审计、次数与时间，可选登录 IP。已有会话访问不意味着当日必有新登录审计。
2. `classroom_access`：该课堂认证接收批次、页面访问与操作类型/次数。平台登录不等于进入某门课。
3. `learning`：保留的合法学习区间在指定窗口内裁剪、去重后的秒数。可见、聚焦且未超过空闲阈值才获得学习时间；跨页、跨标签和重试不能重复加时。
4. `collection`：measured、observed_zero、no_observation、gap、pending、error，以及原因和批次数。有效秒数与完整性独立；有正数也可能存在缺口。

`recorded_seconds` 与全体平均是已记录下限；`measured_seconds=null` 表示缺少可判定的观测，不能当作真实零或缺勤。只有有效区间观测在窗口中且没有已知错误/缺口时才标 observed_zero；仅初始状态心跳、批次包络跨过空窗或服务端操作不满足条件。非零平均排除零值。

## IP、并发与生命周期

公网唯一入口 nginx 将 X-Forwarded-For 覆盖为观测到的 remote_addr，避免学生自填转发链污染新登录/诊断的 IP。历史 IP 未按新口径重新认证；NAT 共用 IP 不能证明某台教室电脑或某个人的位置。业务观察行目前不单独复制请求 IP，登录审计与诊断的 IP 各有来源。

诊断最多20条/请求，按账号与课堂对新增诊断实施60条/分钟的有界限流，已有 ID 重试可直接核对；429 返回 Retry-After。观察按角色、账号、课堂与批次唯一，使用 actor/time 与 classroom/time 索引；统计采用批量名册和分块查询，无逐学生查询、DDL、会话清理或画像生成。

明确删除账号/课堂时清理观察中的个人信息。课堂合并保留原课堂编号的不可变收件/观察事实和审计快照，目标课堂不凭空产生新观察；后续签到需要按合并 lineage 核对原课堂证据。

观察原始行暂不自动清理。未来整学期签到必须增加日报/证据摘要归档，再确定原始行保留策略和分批清理；当前七天区间保留不能冒充整学期完整轨迹。原始隔离批本地存档量增长会触及浏览器配额；此时继续保留内存证据并上报存储故障，不能保证浏览器关闭后的恢复。
