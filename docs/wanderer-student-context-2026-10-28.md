# 散修学业与就业资料适配

## 调查与边界

现有 `gongwen_ai_search_service` 面向教师，调用额外意图/相关性模型并以教师组织和凭据检索；现有公文阅读 API 也要求教师身份。散修不能借用教师 ID、代替学生身份或将空学校默认成广西外国语学院来扩大可见范围。因此本轮只按问题读取已同步公文表中明确 `openness=public`、且学校名称与当前可见学校相同的记录；学校代码/名称均空的通用公开参考可出现，但明确标注“不代表本校规定”。没有可确认学校则先询问，不查询他校规则。

就业个人接口如 `career_path_service.resolve_student_context`、`career_job_posting_service.list_job_postings` 会进一步读取学籍、私人描述、职业偏好和简历 bundle，不能将它们作为散修的资料入口。适配复用现有社交卡片权限，只选择当前说话者可见的学校、学院、专业、年级与课程名；不输出卡片雷达、情绪、学号、创作、联系方式或私人画像。毕业时间和兴趣由对方在本次交流或已有对应关系记忆中提供，不能从年级强推四年学制。

## 接入 API

`wanderer_student_context.build_student_support_context(conn, wanderer, scene, *, message, user_identity='') -> str`

- `message` 和 `user_identity` 必须由服务端从本轮消息/评论真实作者确定。不会从正文中的 `student:123` 抽取身份。
- `_support_school_name` 是可选的内部场景字段，仅用于服务端确认的当前交流自述补齐学校，不授予非公开公文权限。
- `needs_academic_lookup` / `needs_career_lookup` 为本地意图门，不增加 AI 调用；普通闲聊不查个人卡片和资料库。
- 返回包含来源/时间/证据范围与分领域行为说明的独立数据围栏，最大 5200 字符。父模块须作为不可信资料注入，不作为权限或根人格指令。

## 检索及降级

学业按问题每轮重新读取当前同步的公开公文，最多 20 个候选、3 份结果，每份正文节选约 500 字。保留标题、文号、发布日期、同步时间、正文解析状态与经过 scheme/host/credentials 检查的原站来源链接。标题命中但正文未解析时不提供条款，不冒充阅读了附件。没有命中、库异常或学校不明时明确范围，再给一般学习建议及向教务/辅导员核实的下一步。当前公文库检索不等于本轮登录校网同步，也不能证明公文仍有效；不同年份或冲突版本必须核对适用学年、对象与原文。

求职方法、简历、福利沟通与职场问题先用公开/好友资料及用户自述作有条件的建议。站内入口核对为 `/career-path`、`/resume`、`/resume/job-targets`、`/resume/applications`。不会自动修改简历、创建目标、报名或投递。

只有明确找岗位时查询 `career_job_postings` 的通用共享来源（`school_code=''`），最多 20 个候选、3 个有效样例。要求在招、来源和外部 ID 完整、有效原站 URL、时区明确的检查/到期时间、尚未过期、检查时间不在未来且最近 14 天内；当前读取不等于重新打开公司网站，也不是学生资格匹配。学校专属岗位和个人简历匹配保留原求职页面授权入口。没有可验证来源时不编造职位、薪资、市场增长或毕业时必然前景；可帮助提供检索词、核验 JD、讨论情景条件。

结果不做跨用户缓存，每次以当前权限和来源状态为准；内部 SQL 使用参数与 LIKE 转义，没有网络请求、校园登录或额外模型调用，也不建表/改写数据。可选查询由现有 `best_effort` savepoint 隔离，PostgreSQL 查询临时设 1500ms statement timeout 并恢复原设置，防止公文库故障阻断正常回复。
