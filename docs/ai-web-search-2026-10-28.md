# AI 公开网页搜索（2026-10-28）

按用户确认的产品口径：普通对话及深度思考共用每账号每日 10 次；教师 Agent 使用独立的每日 10 次；每位散修独立每日 10 次。管理员没有额外豁免，日期按平台时区（当前 Asia/Shanghai）零点重置。搜索额度独立于模型 token 和既有散修 AI 调用预算。

## 官方接口与范围

已阅读 [DeepSeek Search/Fetch 使用指南](https://api-docs.deepseek.com/zh-cn/guides/search/)、[Tool Calls](https://api-docs.deepseek.com/zh-cn/guides/tool_calls/) 和 [思考模式工具续轮合同](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)。使用固定的 `POST https://api.deepseek.com/v1/tools/search`，以已有 DeepSeek 服务端 Key 鉴权；每次最多 5 条，开启 `need_content`，仅接受 1–128 字符精炼查询。无需新增生产密钥或把 Key 发往浏览器。

Search 已能返回正文，因此本轮不向模型另开放 Fetch，避免一次搜索隐藏追加抓取费用。若以后开放 Fetch，必须复用同一账本和身份授权，不能增加不计额旁路。明确无结果/HTTP 失败不计使用，已发出但结果未知时保留占用。官方当前成功单价为 0.005 元/次，仅用于使用成本说明；实际账单以供应商为准。

本次统一普通聊天、Agent 的公开搜索工具和散修行动。职业网络生成、软件资料识别等原有独立后台研究流程保留原行为，不借其无身份摘要接口执行新的用户搜索。

## 数据与派发合同

- `ai_web_search_daily` 的主键是日期、身份类型、身份主键和通道。`teacher:1` 与 `student:1` 不混账，散修使用真实 `wanderer_agents.id`，不会向给它发消息的好友扣额。`used + reserved + unknown <= 10` 同时由数据库约束和原子事务保护。
- `ai_web_search_calls` 保存请求指纹、防重 ID、派发令牌、状态和有界结果。相同身份/通道的 logical ID 跨日唯一；重复请求只重放，换查询复用 ID 返回冲突。原日请求跨午夜完成仍结算原日。
- 主应用短事务预留后提交，再向 AI 微服务的私有 `/api/ai/search-dispatch` 发带用途隔离 HMAC 的请求。AI 服务核对签名、时效、指纹和令牌，数据库 CAS 只允许一个派发者。任何 HTTP 期间不持数据库连接。
- 明确失败/空结果释放；成功即消耗，即使后续模型回答失败也不退款。非空结果全部因链接安全被过滤时仍扣额，且不给模型任何可冒充已查证的资料。已发出的连接丢失、200 响应损坏或过大归 unknown，不自动退款重发。未发出的租约过期才释放；进程中断后发出过的租约转 unknown。
- 取消发生在数据库线程运行期间时，shield 等待其结算：尚未发出的预留释放，已赢 CAS 但尚未开始 HTTP 的请求记明确取消失败，避免无故挂账。HTTP 已开始的取消保留占用并由 worker 收口。
- 只对明确的 408/429/5xx 响应重试一次；不盲重试读超时、401、402，不跨供应商绕过账本。并发最多 4、队列等待 3 秒、整个供应商调用最多 28 秒、响应体最多 256KiB。
- 每条结果先检查公共 HTTP(S) 链接，拒绝凭据、私网/本机地址和危险协议；总缓存不超过 24KiB，账本硬上限 32KiB。外网资料有独立非可信边界，不作为平台授权、学校规定或长期知识固化的证据。
- 查询拒绝联系方式、学号/凭据模式；模型只提交必要公开主题。身份元数据、页面/隐藏画像、私聊全文不随搜索查询发送。`ori_question` 留在本地。用户回答应附支持事实的真实来源链接，无法核验须说明。
- 7 天结果正文由现有调度器每小时清理最多 500 条，保留请求指纹/终态防重记录，不重新获得派发资格。维护任务去重键 `ai-search:cache-cleanup`。

## 三种入口

普通聊天默认关闭“联网”；用户开启后才做一次有界搜索决策，不需要时不搜索。规划经过 `ai_gateway_post` 的 P1 归因，身份只在服务端元数据中。普通与深思始终使用 chat 通道，图片能力切换也不改变额度。workspace 的请求指纹包括联网开关；完成重放不再规划或搜索，并读取当前额度。HTTP 额度旧响应不能覆盖更新后的流事件，失败也不能抹掉新状态。

Agent 的 `web_search` 经过已有 `web:fetch` 授权桥、实时任务状态和真正 owner 校验，以 task ID 和 SDK 工具调用 ID 防重。撤销授权/取消后不派发；模型参数不能自选身份、桶或额度。原每任务上限继续保留，日额以持久账本为准。

散修的统一 `generate_turn` 主动获得当天额度、成功/在途/待确认/剩余和重置时间，可按人格及问题需要决定是否搜索。最多 2 次搜索、3 轮模型，每一模型轮继续预留既有 AI 预算，总时限不扩大；同轮重复查询复用结果。保留标准工具调用、`reasoning_content` 和 tool 续轮，最后仍严格解析 action/parts/learning JSON。天道裁决、造人和记忆摘要不开放搜索；严重自伤的本地优先响应不等待联网。

普通 AI 的 LQ 按钮及状态文本显示真实余量；散修公开主页和后台个人详情显示聚合统计。包括 unknown 待确认，避免成功数与剩余数字看似矛盾；不显示查询、来源会话、派发令牌或搜索历史。
