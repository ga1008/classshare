## Git 同步及边界

最终 Git refs、远端删除结果、分支代码一致性及当前工作分支由同一证据目录的 `final-git-state.json` 记录。远端更新使用预期旧 SHA 核对，避免覆盖另一任务新提交；只有最终复读确认 `dev/main/origin/dev/origin/main` 同一 SHA 且远端仅两分支，才报告完成。

本轮仅整合、测试与同步 Git，没有部署应用、连接真实业务库测试或修改生产数据。原生测试使用新建回环集群；两项符号链接跳过不是通过，也不能由静态源码清单替代。旧消息生成 formatter 原有去 Markdown、逐行 trim 的合同未调整，代码保护验收证明本轮 guard 不增加损坏，不承诺该旧 formatter 端到端逐字保留代码。非 Chromium、微信真机和长期负载不属于本轮验收。
