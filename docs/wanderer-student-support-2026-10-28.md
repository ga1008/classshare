# 散修学生支持：学业、就业与用户主导的情感陪伴

## 实施前调查与设计

基线为 `567c7e78b62e8a8f35f9f9a7846e24c24f7012ad`。复用既有声线、按关系隔离的个体经验、权限和持久收件队列，不把全部聊天变成咨询。

学业按明确需要即时检索当前已同步且散修有权读取的公开公文，附文名、发布日期、同步/检索时间与来源。公文当前为教师权限链，不能借教师身份读取校内限制内容；无结果、未解析、来源冲突或学校不明时应说明并协助向教务确认，不伪造政策。检索当前本地库与实时同步校网是两件事。

就业使用对方本来可见的资料和主动提供的背景，按毕业时间、方向、城市作条件推演，提供简历、岗位、公司核验、面试、福利与职场沟通帮助。现有简历/职业私有画像不能因为添加散修好友就被读取，也不自动写入或投递。岗位样本与来源时间只能支持有限判断，不能保证未来工资或就业。

情感支持在本轮真实用户表达需求后进入，保留角色差异，允许聊感情、喜欢、失恋、关心和适龄的虚拟互动。默认年龄未知，不读取私有简历生日来推年龄；恋爱话题不是无限制的性内容开关。当前撤回优先于历史，对群聊和主动消息不继承私人关系。电子人身份保持诚实，不用排他依赖、保密约束、永远在线或线下承诺制造被爱感。不会注入让模型绕过安全边界的越狱提示。

高风险消息不能只靠模型提示：既有队列会在 cap 后延至次日，也可能随机 skip/emoji。新增有界零模型安全支持快道，仍用原 row/lease/nonce/发送进度和权限，危机回复不能被日 AI 配额挡住，正常反刷限制和运行开关继续适用。纯规则作为低延迟兜底，模型仍需理解复杂语境；不声称自动筛查完全准确或保证实时医疗服务。

参考 DeepSeek 官方 Chat Completions system 消息合同，以及 WHO 与 NIMH 关于直接询问、倾听、帮助远离危险并连接现实支持的资料。热线工具本次仅返回不匹配本平台地区的资源，未固化该号码，不猜测当地热线。紧急文本使用当地急救、校园值班/保卫部门与身边可信任的人，不假装平台已经通知或报警。

所有验证使用隔离合成数据库/模型替身，重点验收用户触发与撤回、不同好友隔离、真实来源与过期、不造未来数据、cap/失败/skip/重启/撤回/权限变化、低境界内容完整，以及队列并发边界。冻结后执行原生 PostgreSQL 演练、DryRun、正式部署、只读上线核验及远端 Git 一致性检查，保护 `/lanshare/data`。

## 实现与闭环

- 共享 `wanderer_student_support` 按服务器确定的当前人类消息选择学业、就业、情感路径，可混合；旧摘要、引用、自己的话或散修互答不产生新的危机或恋爱许可。普通闲聊不强行咨询，主动联络、公共场景不继承私聊浪漫互动，当前撤回优先。
- [学业/就业资料适配](wanderer-student-context-2026-10-28.md)复用现有好友卡片可见资料，只读查询本校完全公开公文及明确降权的通用公开参考。公文附文号、发布时间、同步时间、正文状态与原站链接；未知学校先询问，未解析/未命中/冲突不伪造条款。岗位仅有效通用来源、最近 14 天检查、不在未来且未到期。未来就业按毕业时间与方向作有条件推演，不读取私有简历、隐藏画像或个人匹配包。
- [情感与风险规则](wanderer-emotional-support-research-2026-10-28.md)允许用户主导的温暖陪伴、恋爱讨论与合适的非性化虚拟互动。年龄未知不推断成年，身份混淆时诚实解释，不每轮重复免责声明。拒绝、第三者转述、预防教育不错误授权或升级；引用后真正披露当前危险仍认真回应。没有注入越狱提示或改动生产 DeepSeek 端点。
- [发送闭环](wanderer-support-delivery-2026-10-28.md)保留正常默认 2 路模型任务，独立最多 1 路无模型安全 lease。新增 `support_urgent`、`lease_lane`、`support_handled_message_id` 与索引；先补列后建索引，旧表可迁移。安全支持走原 row/token/nonce/发送进度，不绕运行开关、权限或反刷限制。
- 新紧急消息能唤醒因额度延期的队列，并协作取消同会话正在等待的普通生成，再交安全通道；已预留额度不退回，不声称远端计费调用已经撤销。生成期间撤回亲密意愿时，未发送的旧内容停止；已有分段不归零、不重复。安全源独立游标不跳过普通未处理问题，积压后的同一风险不机械重答，新危险仍处理。
- 博客/群/课堂在随机忽略前检查明确当前风险；课堂失败或节流未送达时不推进 seen 游标，保留下一次合法尝试。学习与摘要不固化永久风险、心理诊断、排他恋人身份或永久义务；正常表达偏好仍可按原关系保存、纠错。
