2026 年 11 月 23 日。本次实现覆盖课堂主站、独立内容站、独立游戏包和教师管理。测试使用可清理的合成账号、游戏文件、SQLite 库或回环 PostgreSQL 临时集群。生产放行取决于下表中的环境验证与容量记录。

| 用户流程 | 本次实现与核验 |
| --- | --- |
| 从平台找到游戏并开局 | “观点与交流”右侧进入大厅。桌面显示卡片和四组侧栏，390px 宽度可操作。卡片有指针背光和键盘焦点，点击在新标签打开游戏宿主。三款示例的封面、最近游玩、近七日人数、好友同意公开的在玩状态与教师推荐均使用真实后端生成。 |

## 关键边界与证据

正式前端构建的静态资源版本为 `b7e3c2032f4378c02aa496771bd0d9e45c39190e1f093754fbd96bcaee893837`。本轮 `test_minigame*.py` 共 50 项全部通过，启用了真实浏览器用例，跳过数为 0。另有 6 项页面组件回归通过。保持登录、教师菜单、界面偏好、合班成员、社交范围与好友、既有题包、路由及部署保护的 165 项既有回归通过。源码审计覆盖 628 个文件和 215 个模板，共记录 5,861 个组件使用位置。

- **游戏内容与账号隔离。** 两个回环 HTTPS 主机经 Nginx 1.27.5 代理，真实浏览器完成 SDK 操作。主文档和 HEAD 为 200，分段读取为 206，续租成功，下架后旧地址为 404。内容服务收到的请求中无主站 Cookie 与 Authorization。访问日志已遮蔽资源句柄和续租标识。生产代理采用权威鉴权后由内容 ASGI 在读锁内发送文件，Nginx 转发响应。[可复验的 HTTPS 探针](../../tools/minigame_https_probe.py)
- **课堂可独立服务。** 主站、可信游戏 API 和内容站分别运行。实际停止游戏 API 进程后，续租请求返回 502。同一代理下的课堂健康接口与已登录学生首页仍返回 200。失败请求的访问和错误日志也通过了凭据及租约标识检查。Linux 部署在请求时通过 Docker DNS 解析可选上游。[可信 API](../../classroom_app/minigame_api.py) · [代理配置](../../deployment/nginx-game-api-location.conf)
- **上传包的环境差异。** 本机 Chromium 在平台沙盒与离线模式分别验证图片、字体、音频、视频首帧及 JSON。Windows 的测试执行器仅接收预先审阅的合成摘要。生产 Linux 采用非 root、无外部网络、受 seccomp 限制的独立容器，目标宿主上的 sandbox 启动、超限与失败恢复仍属于上线验收。[生产执行器与恢复方法](../../deployment/docker/MINIGAME_PROBE.md)
- **数据库。** 初始化与升级在同一事务内验证 27 张表的必需字段、主键、索引和种子记录。在原生 PostgreSQL 16.14 中让两个独立 CLI 同时等待迁移锁，放行后两者均通过。移除一张管理表后检查能指出缺项，重新迁移可恢复。只读状态检查在 SQLite 数据库不存在时不会创建文件。[迁移工具](../../tools/db/migrate_minigames.py) · [迁移回归](../../tests/test_minigame_schema_migration.py)
- **同一存档的竞争写入。** 两个 PostgreSQL 事务分别提交等级 2 和 1。早先实现曾在高值先提交时回退到等级 1。现有实现按账号固定顺序锁定存档行后比较等级，重放保留等级 2，只登记实际前移。低值先提交时，日志依次记录 0→1、1→2。真实行锁超时后整次操作回滚，重用原请求键可完成操作。[存档事务实现](../../classroom_app/services/minigame_runtime_store.py)
- **还原删除前的备份。** 真实 `pg_dump` 与游戏文件副本还原到另一 PostgreSQL 数据库和目录。错误的库外签封摘要被拒绝。正确重放清除了目标的 2 个版本、28 个文件、进度与活动，并撤销副本中 4 个旧租约。另一款已发布游戏的 13 个文件逐一通过 SHA-256 核对。第二次检查显示待删除数为 0。[PostgreSQL 演练](../../tools/minigame_package_pg_probe.py)
- **课堂共用资源。** 在两个逻辑核、4 GiB 的服务端预算内，200 名合成玩家组成 20 个十人房持续 30 分钟。课堂分组二维码读取在基线 599 次和混压 8,983 次下的端到端 P95 分别为 5.92 ms、6.43 ms，增加 8.61%，达到本次不超过 10% 的目标。上传验收窗口的 35 次课堂读取 P95 为 12.67 ms。游戏短同步 P95 为 69.68 ms，动作 89.04 ms，所有九名同伴均收到动作的 P95 为 1.922 秒。HTTP 5xx 为 0，负载客户端有 6 次连接读取中断。十名模拟订阅者均收到倒计时的 P95 为 539.05 ms，服务端开局偏差 P95 为 188 ms。页面真正绘制五秒倒计时另由双账号浏览器验证。课程提交、整套生产服务、Docker DNS 和校园网络需要在目标环境取证。[完整容量与故障记录](runtime-verification.md)
- **前端。** 真实发布后，桌面与窄屏截图保存在本机证据目录 `.codex-temp/evidence/minigames-v21-hall/`。桌面 1440px 的 CLS 两次均为 0.00001564，390px 触屏模拟均为 0。两种宽度均能用 Tab 聚焦游戏卡并用 Enter 打开独立宿主，减少动态效果模式关闭跟随背光。68 秒主动开局、轮询和续租期间只观察到小游戏 API，后台同步也经过考勤隔离测试。源代码审计、正式静态构建和浏览器交互分别取证。[大厅与管理浏览器用例](../../tests/e2e/components/minigames.spec.ts) · [真实双端游玩用例](../../tests/test_minigame_multiplayer_browser.py)
- **共享首屏脚本预算。** 两次完整构建得到同一个资源指纹。11 份同步模块的实际 gzip 响应合计 18,423 字节，较原来的 18,894 字节减少 471 字节，符合 18,432 字节上限。Chromium 从正式产物分别加载了 21 项按需能力。静态构建会把编码器版本纳入资源指纹。
