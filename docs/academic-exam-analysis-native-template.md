# 教务试卷分析表原生模板

`classroom_app/services/assets/gxufl_academic_exam_analysis_template.docx` 是教务导出 RTF 经 Microsoft Word 转换后直接脱敏的 OOXML 包。它保留原始文字、表格、合并关系、字体、段落属性和图片定位，供填充器向原生单元格写入当前材料数据。

## 来源与校验

- 转换后的未脱敏 DOCX SHA-256：`976970c62f038e6166cf7d273c55d0a4539b8f8a119b840c4e3911d84391620e`。
- 本模板 SHA-256：`073bbd7f624da1608919b20209e8aaa773aa945fb51eefffc16839cdf1d7d2b6`。
- 版式交叉核对使用用户提供的《服务器配置与管理》试卷分析表 DOC/PDF。该 DOC SHA-256：`b7546a38b1b875bd6898b0c562b1e554cee30b74e819f38f426d4198c71ab72e`。该文件是人工填充后的参考，分析区和审核区高度与未填写的教务导出有所不同，不应混用两者尺寸。

资产只删除动态槽中的 `w:t` 内容、作者/时间/编辑标识等非版式元数据，并将示例成绩图替换为同像素大小的透明 PNG。未重建表格或段落，未保留课程、教师、班级、成绩和个人签名。静态学校标题和表头保持原样。原件第三行白色不可见的文字是动态值，模板中已清空；有真实来源时填入该原件的隐藏文字，只有业务载荷时默认留空，始终保留其白色字体和原段落格式。ZIP 条目时间统一设为 1980-01-01。

## 保真边界与验证

- A4：11905 × 16837 twips；上下边距 388、左右边距 1080；页眉页脚距离 720。
- 原生固定表格 23 行；`tblW=9644`、`tblInd=5`，不改为居中；原 `tcW` 与 `tblGrid` 的微小差异均保留。
- 网格：434、930、630、1080、570、870、1425、915、1080、840、870 twips。
- 学生班级由两行各 280 twips 纵向合并；最高/最低分行使用原有独立合并关系。
- 原始分析正文行 2840 twips；审核标题/意见/签字分别 280/1860/320 twips，通过原生白色内部边线视觉连接。人工填充的参考文件调整了这些高度，不能当作原始空模板的尺寸。
- 保留元数据宋体 9 pt、固定 10.8 pt 行距、1 pt 左缩进；分析提示宋体 11 pt、固定 13.2 pt 行距；标题 16 pt、固定 19.2 pt 行距；页末注释在表格最后一行。
- 脱敏时按允许槽清空文字后，`document.xml` 与源文件进行规范化 XML 比较完全一致（仅额外删除编辑修订标识）。原图和关系未发生布局变动。
- 已通过 `render_docx.py` 的 LibreOffice 渲染以及 Microsoft Word PDF 导出，均为一页，并逐页检查了 PNG。不同排版引擎的字体光栅化差异不应通过重建原版文字、改变表格或修改字号来补偿。

真实教务记录的预览和导出必须携带本次归档的 RTF 原件，并通过文件哈希及版式指纹校验。只有原件的表格行声明、字体表、段落格式等与已审计版式兼容，才使用本资产中的原生文字和表格，填入该原件的只读字段、成绩统计及原始图表；用户填写内容和授权签名插入各自区域。运行时不调用 LibreOffice 重新将 RTF 转换成 DOCX，避免引入排版转换差异和额外并发开销。原件缺失、损坏或版式未知时明确拒绝导出，不以本资产静默替代未知来源。仅底层纯 payload 生成与测试可以直接使用本资产；这条路径不作为真实教务记录缺失原件时的回退。
