# 卡片导航拖动、点击与删除

接续 `lessondoc-page-rail-2026-09-03.md` 的单一绿色插入标记。此次改动仅涉及编辑器前端，沿用页面模型、保存 API、版本冲突和撤销重做机制。

## 交互设计

- 在卡片上按住鼠标左键，移动超过 5 px 后横向拖动整个导航区；移动量与滚动量一比一。松手结束，没有惯性漂移或额外点击。
- 卡片内单击切换页面；5 px 内的手抖仍按点击处理。按下点属于卡片时，即使轻微移到间隙也不会误新增。
- 从间隙按下并拖动，不横滚、不新增；拖回原点也仍视为拖动。直接单击实际间隙任何位置可新增，保留顶部圆形加号及距离渐显。导航末尾的大块空白不属于插入间隙。
- 卡片实际矩形优先于插入按钮的放大点击区，避免卡片边缘被新增按钮截走。首尾间隙、键盘方向键、Home/End、Insert/+、Tab/Enter 继续可用。
- 无元素选中时显示页面属性，右侧底部固定显示“删除此页面”；选中元素时显示元素属性，不显示页面删除按钮。删除后选中接替位置的页面，删除末页则选中剩余末页。
- 页卡悬停、选中边框使用短过渡。插入淡入、后续卡片前移采用 160 ms 动画，仅动画可见卡片；拖动开始立即取消动画，保证跟手。系统设置减少动态效果时关闭动画。
- 保留一页下限、40 页上限与预览禁写。鼠标逻辑不接管触屏原生横向滚动。

## 实施与业务闭环

`page_rail_pointer.js` 是无 DOM 的命中判断和按压状态：卡片与间隙的几何范围、点击阈值、增量滚动与边界限幅。到达边界后反向拖动立即生效，不必拖回越界前的位置。

`page_rail.js` 用 Pointer Capture 接住移出导航的鼠标，按帧合并滚动写入；拖动期间不修改文档，不触发保存或整栏重建。松手、取消、失焦、文档变化和卸载都结束手势并抑制误点击。继续按稳定页面 ID 复用卡片节点，避免属性更新或自动保存导致导航重建。

属性栏删除通过 `index.js` 回调调用原 `pageCommand`，不另建一套删除逻辑。统一页面变更命令先将旧式数字跳转绑定到稳定页面 ID，再执行插入、删除、复制或移动，最后重算跳转页码。删除会清除指向已删页面/内部元素的动作，以及全局元素中过期的页面排除 ID；其余目标保持不变。所有修改归入一个命令，可一步撤销恢复内容和引用。

样式集中在原编辑器 CSS。没有新增第三方依赖、后端 API 或数据库字段。
