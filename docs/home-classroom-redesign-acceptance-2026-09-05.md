# 首页与课堂页改版：验收标准与测试矩阵

日期：2026-09-05。对应[改进方案](home-classroom-redesign-plan-2026-09-05.md)，基线 `dev / c79f1674`。

状态：本表是在实施前制定的验收要求，保留原标准作为对照。改版已实施；实际执行结果、覆盖范围及明确偏差记录在[实施验收附录](home-classroom-redesign-verification-2026-09-05.md)，不能仅凭本表中的测试名判定通过。

## 1. 如何判断完成

改版必须同时做到：信息准确、主次清楚、完整内容可达、原有业务不中断、性能不因“收纳”反而变差。不能用“截图变好看”替代功能验收，也不能通过删除旧断言而不补新行为断言来获得通过。

验收分三级：

- **A：阻断交付。** 漏任务、错状态/日期、权限泄漏、丢失提交/草稿、无法打开材料、失去历史入口、关键内容不可访问、构建产物不一致。
- **B：改版必须达成。** 重复面板退役、首屏行动可见、长名称不挤压、间距与视觉统一、二级返回连贯、预览与全量一致。
- **C：测量后持续改进。** 线上真实用户性能与长期任务效率。不能把尚未采样的线上数值填成通过；明显实验室回退仍阻断发布。

## 2. 基线与测试数据

### 2.1 统一记录

每份报告记录提交、角色、数据集 ID、时区/固定时间、视口、浏览器缩放、字体、主题、网络/CPU配置、是否冷缓存、请求/查询数、截图路径。前后对比必须使用同一份授权数据与同一环境；用户截图用于定性对照，不能直接作为像素高度或耗时基线。

先用 P03 隔离运行环境建立数据；确认健康接口指向隔离数据库，不能连接工作数据库、生产教务、真实邮件或真实 AI。SQLite 场景与 PostgreSQL 场景分开记录，不以一种数据库通过推断另一种也通过。

### 2.3 时间样本

至少固定在 `2026-09-05 10:00 +08:00`、`2026-09-06 23:59 +08:00`、`2026-09-07 00:00 +08:00`；再覆盖 UTC 带 Z、显式 +08:00、系统约定的本地 naive 时间、仅日期、无截止日期。时间解释需符合字段合同，不一律通过删除时区标记处理。

## 4. 首页与课堂的任务路径验收

“一次操作”指用户的一次激活，例如点击/Enter；输入关键词不计成多次点击，但必须记录。一级预览中高频动作直达现有目标；完整集合允许先打开面板再选条目。不要用悬停2000ms当作一次可预测导航。

| ID/级别 | 用户任务 | 验收标准 |
|---|---|---|
| H01/B | 登录后决定下一步 | 1366×768、390×844下，可见唯一最重要行动及至少一个课堂入口；不先滚过统计墙 |
| H02/B | 找课堂并进入 | 搜索/学期/状态筛选可用；卡/行里1次激活进入；空结果可清除条件 |
| H03/B | 查远期和无日期事项 | 1次激活打开完整事项，默认可见条目再1次进入详情；筛选/翻页单独记录查找操作，不作为新增导航层级；支持课程、类型、日期范围/时间组、状态过滤并明示范围 |
| H04/A | 完成/编辑个人待办 | 新增、编辑、完成、原有删除/提醒行为不丢；教师默认不关联课堂，学生维持授权课堂选择与编辑不可改课堂规则；两者均本人私有 |

## 7. 无障碍与说明卡验收

规范依据：[WCAG 2.2](https://www.w3.org/TR/WCAG22/)、[重排解读](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)、[目标尺寸解读](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)、[悬停/焦点内容](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus)。APG为实现指导；说明时延是本项目既有合同。

| ID/级别 | 内容 | 性质及通过条件 |
|---|---|---|
| A01/A | 文字与非文本对比 | 普通文字≥4.5:1、大文字≥3:1；识别控件/状态必需的非文本内容≥3:1，例外按WCAG处理 |
| A02/A | 重排与放大 | 320 CSS px普通内容不丢功能/信息，不要求全页双向滚动；200%文字放大无关键截断 |
| A03/A | 键盘可用 | 所有功能可键盘操作，焦点可见且不被自制浮动导航完全遮挡；无无标签图标操作 |
| A04/A | 点击目标最低要求 | WCAG AA为24×24 CSS px或符合标准规定的间距/等效等例外，不能误写成AA统一44px |
| A05/B | 项目触控目标 | 主要操作和粗指针图标触控区域≥44×44px；现有说明按钮40px应单独补齐或明确记录偏差 |
| A06/A | 统一解释卡 | 可悬停/聚焦/点击阅读；移入说明卡不中断；Escape可关闭；阅读期间不自动消失 |
| A07/A | 说明可发现性 | 必要解释有显式按钮；不只挂在不可聚焦section；带链接的非模态卡可用键盘进入链接并返回 |
| A08/B | 既有时延合同 | 默认hover 2000ms、focus 300ms、长按650ms；触屏移动>10px取消长按，短按不拦正常动作 |
| A09/A | 模态面板 | 标题与语义正确，打开焦点进入、Tab约束在内、Escape关闭、背景不可交互，关闭焦点回触发器或合理位置 |
| A10/A | 非模态解释卡 | 保持非模态dialog语义，不强行施加模态焦点陷阱；悬浮打开不抢用户正在操作的焦点 |
| A11/B | 动效与媒体 | reduced-motion关闭非必要过渡；解释媒体首次打开前无请求，单页只创建一个统一说明浮窗 |
| A12/A | 必须常显的信息 | 截止/补交约束、提交结果、生成失败、权限阻断、材料未配、组内未揭示均不只存在于hover卡 |

自动工具可检查部分语义/对比度/尺寸，不能代替键盘、触屏、阅读顺序和浮层返回的人工操作。测试期间记录实际问题，不以“使用了Radix”代替验收。
