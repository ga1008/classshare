## 资格引擎边界与导入前守门

本次使用真实 JD 文本和合成履历做纯函数验证，未接触业务数据库。合成履历为“本科 2020-06 毕业、2020—2025 年正式工作、CET-4/CET-6 均仅 300 分”。研究时的规则只提取出学历、专业、证书名称三项，三条岗位都错误满足了 `confirmed` 的计算表达式。原始反例和当时两个服务文件的 SHA-256 已保留在证据清单，便于与后续修复比较。

| 条件 | 研究时能表达的部分 | 不能据此确认的部分／安全状态 |
|---|---|---|
| 本科及以上 | 学历层次、已填毕业年月；尚在读会待确认 | 自述层次不证明证件原件、学位授予或岗位身份条件 |
| 2027 届／应届身份 | 尚无独立届次和首次就业规则 | 必须保留 unknown；仅在明确单一年份要求且教育时间证据明确不符时，才可提示已知届次差距 |
| 2026-01-01 至 2027-07-31 毕业区间 | 现有教育结束时间只能用于一般毕业状态 | 尚不能精确比较复杂日期区间与国内外不同分支，应列 unknown |
| 毕业后初次就业 | 能统计部分正式工作经历时长 | 没有经历记录不等于从未就业；“首次就业”及政策例外必须 unknown，不能默许通过 |
| 境外毕业／留服认证 | 有学校、专业和学历文本 | 学校文本不能证明境外学历属性、回国状态或留服认证，必须 unknown |
| CET/IELTS/TOEFL/TOEIC 分数 | 能识别部分证书名称与有效期 | 仅存在 CET-4 记录不等于达到 425 分；英文别名、分数门槛和等效证明必须待确认 |
| 多种证书任选其一 | 原规则逐个证书检查 | 不能将 OR 当成全部必需；某个过期备选不能直接推出整组 failed，未知组合应 unknown |
| 专业限定 | 自述专业在条款中明确出现时可提供匹配线索 | 相近专业、学科门类、排除条件和招聘方裁量不自动映射；模糊范围保留 unknown |
| 证书取得时间 | 规则本身会检查取得年月 | 招聘列表的资料查询当时未取 acquired_date，会丢失未来取得证据；修复查询字段后才能可靠保留未来证书 unknown |

因此这批数据在资格提取覆盖守门修复前保持为纯候选。`confirmed` 必须排除任何未支持的硬条件；`no_known_gaps` 只能表示未发现**已知**差距，仍须逐项展示 unknown，不能宣称已具备报考或录用资格。后续修复应保留这些真实 JD 合成反例，以免添加一种证书规则后重新遗漏应届身份。

本轮随后已完成最小守门修复：复杂毕业区间、应届/首次就业、境外认证、成绩与备选证书新增显式 unknown；单一届次且全部已填教育毕业年份均不符才提示已知差距；证书 OR 不再逐项当作 AND；资料查询保留取得日期。三条真实 JD 合成反例在修复后均不能进入 confirmed。已通过 162 项职业与简历相关回归（1 项可选 PG 测试跳过），另实际运行了隔离 PostgreSQL HTTP 验证，证明未来证书与未支持条件被 confirmed 筛选排除、no_known_gaps 仍展示 unknown，临时 schema 已清理。修复前后证据同时保留，候选仍未导入业务数据库。

## 维护与接入建议

- 先由学校确定来源优先级及维护负责人。当前建议先审核这三个官方候选，校方就业平台获得明确供数方式后再扩充广西、东盟语言、设计和管理岗位；单一银行来源不能代表整体就业市场。
- 初期复用现有受控 JSON 导入工具，每批不超过 200 条。用稳定的 `source + external_id` 去重；只把核验后的职责和资格摘要导入，并保留公告、附件和岗位编号。首次只做本地格式校验及隔离环境验证，生产写入须由根任务按用户已授权范围统一处理。
- 对本批短期校招建议每日复核一次列表状态和截止字段；距截止 48 小时内增加一次人工复核。已撤下、关闭或到期应停止展示；接口失败不能延长截止时间或刷新 `checked_at`。重试须低频、有限次，并使用响应变化摘要避免重复解析。
- 接入周期性采集前先确认官方供数许可/规则。公开网页调用目前没有版本承诺，活动配置、机构 ID、页面结构可能变动；不能把 2024 命名的静态 JS 文件名误当成岗位年份，实际届次来自当前 2027 活动配置与公告。无需向学生页面实时请求第三方网站。
- 现有表的 `city` 是单值，无法精确承载“省内分配”或多城同岗；可以保留为待核验数据，后续增加规范化地点列表、原始地点和地点精度字段。不要拆成多个城市伪造职位数量。`expires_at` 当前作为展示有效期；若后续另设内部复核期限，应与官方 `application_deadline` 分开，以免把运维 TTL 误称为招聘截止。
- 这些岗位并不证明任一学生已经满足条件。推荐依据应使用显式学历、毕业时间、语言证书及专业证据；缺证据时标记待确认，不能由专业名称或求职意向推导取得资格。
