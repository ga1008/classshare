# 2026-09-23 全站模板与材质接入审计

本表是当前工作树的源码审计，不把模板继承、CSS 引用或路由发现等同于页面业务、视觉或实机验收。固定背景必须由 HTML 根接入；正文与控件通过共享材质令牌继承。导出/打印内容保持自身输出规范。

## 范围与判据

- 扫描 templates 下 195 个 HTML 文件、217 个静态路由/模板条目。
- 旧台账登记 190 个模板；本轮发现未登记文件：`macros/lq/nav-menu.html`, `partials/lq_page_backdrop.html`, `partials/profile/appearance.html`, `partials/profile/hero_lq.html`, `student_auth_flow_v4.html`。
- AST 不能解析所有装饰器与运行时分发；无发现路由的 partial/macro 不能视为无消费者。
- 下表“主题/背景”仅描述本文件及其静态引用链。共享 partial 本身通常没有根 HTML，不要求重复加载全站资源。
- 所有 document 根均引用 lq_editor_head，统一加载主题和 Tailwind 的 lq 模块；开发预览根单独列出。

- 简历根补背景；sidebar/topbar 接 chrome，表单/首页/岗位/生成器容器接 content，公共简历弹窗接 raised；局部色值映射到共享主题和语义色。
