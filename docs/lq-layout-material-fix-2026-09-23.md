# 玻璃按钮与板块的多余底板修复

针对用户截图中顶栏胶囊按钮背后的矩形底板，以及待办卡片列表的矩形底板，按实际 DOM 和生产构建 CSS 计算样式追踪并修复。布局壳负责排列，真正的按钮、面板和浮层负责材质。

## 修复范围

- 顶栏：Jinja、原生工厂及手写导航模板移除 inline pane 误用的 `lq-surface`；移动抽屉打开时仍自动获得厚玻璃和焦点管理。
- 首页：待办 `ul` 不再叠加列表面板，材质与高光归属外层 `.ls-focus`；React 接管前后保持一致。学生独立圆角卡片、教师列表及全部操作保留。
- 教师侧栏：暗色旧兼容规则不再填充 LQ 外壳；真实内部圆角表面补齐 SSR 材质。
- 课堂任务：暗色规则不再给卡片正文、顶部及页脚额外刷实心底色；外卡与进度等独立分区保留。
- 首页桌面折叠区与弹窗内日历：透明布局规则优先于共享材质及不透明降级，移动折叠卡和独立日历仍有材质。高对比日历保留 2px 可读轮廓。

没有修改数据库结构、业务 API、权限、草稿或提交逻辑。

## 验证

- 新增真实模板与生产 React island 的 16 项浏览器回归全部通过，包含 SSR、增强、手机抽屉开关、关闭焦点、展开时切回桌面、色对，以及浅深色、关闭玻璃、低能力和高对比模式。
- 既有 Shell/材质浏览器测试 52 项通过；LQ 单元测试 163 项通过。
- 隔离环境后端 LQ 契约 193 项、首页业务 55 项、管理模板 11 项通过。
- 最终独立视觉复核 13 组无失败，检查师生桌面、手机、浅深色及课堂历史任务；额外 8 组真实日历 DOM 宿主组合检查通过。后者是浏览器内组合验证，不冒充首页完整日历业务操作。
- TypeScript、LQ lint（0 阻断）及资源大小门禁通过。
- 最终资源图的师生 × 桌面/触屏 × 浅深色 8 组全页检查通过：96/96 路由返回 200，无页面脚本异常，最大横向溢出 0px。
