# 学习文档编辑器：页面间隙插入

本次接续已完成的编辑器改造，仅调整下方页面导航的交互。上一轮完整架构、施工与发布记录见 `lessondoc-editor-progress-2026-09-03.md`。

## 问题与设计

原导航末尾有“+ 页面”按钮，但实际在当前选中页后插入，按钮位置与作用位置不一致。现在在鼠标最近的页面间隙显示绿色竖线，顶部为圆形加号；第一页之前和最后一页之后也有插入位置。

- 整个导航只创建一个插入按钮。指针距间隙小于 56 px 时渐显，亮度为 `(1 - 距离 / 56)^1.35`，在间隙处最亮，移到卡片中央或离开导航时隐藏。
- 圆形加号在卡片上方，细线沿卡片间隙向下延伸。按钮可点击范围比线宽，保留选中页原有蓝色边框。
- 插入索引直接取实际间隙，不受当前选中页影响；插入后选中新页并滚动到可见区域。首尾预留完整加号空间。
- 无悬停设备在当前页后保留一个可见入口，点击区域宽 44 px。键盘聚焦页卡后按 Insert 或 + 在当前页后插入；左右键、Home、End 切换页卡。Tab 聚焦加号后，上述方向键选择插入间隙，Enter 插入。
- 预览模式隐藏插入按钮；达到每课 40 页时禁用并给出拆分课次提示。新增页进入原有命令、撤销重做、自动保存和版本冲突流程。

## 实施方式与维护边界

`static/js/lessondoc_editor/page_rail.js` 以 WeakMap 为导航容器保存控制器，按稳定页 ID 复用卡片节点。文档或保存事件只更新变化内容、顺序和选中状态，避免重建整个导航造成焦点与滚动丢失。单次指针移动只更新插入标记，不遍历文档对象。

页面间隙在文档变化或容器尺寸变化后测量；指针、滚动和尺寸事件合并到一次 requestAnimationFrame。页面卸载或切换为课程首页时注销监听、ResizeObserver 和动画帧。沿用原有 store 和保存 API，不新增数据库字段、后端接口或第三方依赖。

样式集中在 `static/css/lessondoc_editor.css`，替换原末尾添加按钮；兼容现有窄屏和减少动态效果设置。`page_rail.test.js` 覆盖最近间隙、亮度、首中末插入、稳定目标 ID、一步撤销重做、非法索引、预览和 40 页限制。
