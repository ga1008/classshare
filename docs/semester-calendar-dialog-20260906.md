# 学期日历浮窗修复与验收

## 问题与根因

首页“日程与事项”浮窗原本与事项列表共用 960px 宽度，四张学期概览卡和重复操作挤占周历空间。

横向拖动的白区并非数据缺失：共享日历使用固定宽度网格轨道，依靠 `min-width: max-content` 撑开画布；首页的后置 `.dw-dialog * { min-width: 0 }` 覆盖了它。真实浏览器中，画布盒宽 891px、内容宽约 2828px，而 `clip-path` 按画布盒裁切。拖动 688px 后，画布右界进入视口，后续日期被裁掉。

## 最终行为

- 共享日历画布显式使用 `width: max-content`，完整承载轨道宽度，保留圆角裁切与星期固定列。
- 仅日历视图扩大为距视口边缘 16px、最大 1800px 的浮窗；手机保留 8px 边距。事项视图保持原尺寸。
- 学期选择与定位操作并列，窄屏上下排列；学期概览默认折叠，展开后仍显示日期、周次、进度和节假日统计。重复的“新增待办”入口合并到浮窗顶部。
- 周历自身可横向、纵向滚动，短屏下月份、周次和星期轴保持可见。首页表头和星期轴适度压缩，日期直接显示月/日，去掉重复的日期/星期行；固定轴使用不透明背景，避免透出底层文字。后面的每周事项仍在同一浮窗内可滚动访问。
- 首页调休标签保留“调休上课”和补课日期，完整原始说明与核验信息通过现有统一说明浮窗展示，支持悬停、键盘聚焦和长按。其他调用方保持原标签。
- 日程浮窗显式声明模态语义，使共享说明挂载在日程内部；关闭说明不会被当成点击日程外部而连带关闭日历。

## 数据与功能边界

继续复用原日历节点、控制器、课程筛选、学期选择、事项读取接口，以及新增待办和日历订阅弹窗。本次不修改数据库、权限、API 或定时任务，不迁移、重建或清空用户数据。

## 验收标准

1. 教师和学生在 1440px 桌面及 390px 窄屏打开同一日历视图，选择的学期、日期与事项来源保持正确；页面与浮窗没有额外横向溢出。
2. 拖到学期后段时，右侧仍命中实际日期单元格；画布盒宽覆盖其全部网格内容，左侧星期列不随横向拖动移走。
3. 概览默认折叠，四项数据均可展开查看；完整调休说明通过共享提示卡可达。
4. 选择其他周、切到全部事项、切回日历后，仍是原节点且保留学期与周选择；“定位今天”能回到当前周。
5. 窄屏或短屏可以滚动访问所有日期和周内事项；关闭、Escape 与焦点回到入口可用；新增待办和订阅仍交接给既有弹窗。
6. 编译与类型检查通过，真实页面和共享组件回归通过，无新增浏览器运行错误。
7. 发布前使用干净提交构建、部署预演、独立数据库和文件备份及隔离恢复验证。发布后核对资源、版本、服务健康、挂载和关键业务记录；回滚仅还原代码、配置和镜像，保留发布后新增业务数据。
