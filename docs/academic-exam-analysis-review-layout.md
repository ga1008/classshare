# 试卷分析表审核意见与版式

试卷分析表使用 `department_review_opinion` 和 `dean_review_opinion` 保存两处独立审核意见。编辑卡片将意见放在对应签名点上方；确认签名同步保存本栏意见，整表保存保留两栏编辑结果。标准批语分别为“已核”和“同意”，支持最多80字的自定义意见及明确清空。

未签名、未修改的默认建议不会自动写入材料。旧材料仅在当前版本有有效个人签名、且没有已保存意见或批语章时补标准批语。个人签名和批语章分别解析：批语章位于意见区，个人签名位于签字区；批语章不能代替签名使材料变为完整。明确填写的文字或空值优先于批语章，避免重复显示。

详情、列表及导出均从当前材料版本的签名绑定解析状态；列表批量读取，避免每张卡片逐条查询。保存和重新生成使用材料版本及持久化快照校验，旧窗口不能覆盖较新内容。预览HTML禁止缓存，底层PDF及页面图片继续使用共享文档渲染器的内容哈希缓存。

DOCX 使用经过审计的教务原生 Word 表格资产，在允许填写的单元格内插入内容。v4 契约保留 A4、11 列基础网格、23 行物理结构、合并关系、单元格尺寸、字体、段落属性与边线；页末注释仍在原表最后一行。审核标题、意见、签字分别沿用原有三行及白色内部边线，固定“签字：”文字保留。个人签名与批语图片分别插入对应区域，并限制宽高、保留比例。资产来源、尺寸和填写槽见 [教务试卷分析表原生模板](academic-exam-analysis-native-template.md)。

真实教务记录导出必须取得本次归档的 RTF 原件。运行时先验证文件哈希，再核验原件的表格行声明、字体表、段落格式等版式指纹；兼容时使用审计后的原生表格资产，填入原件只读元数据和成绩统计，直接复用原件图表及图片。导出过程中不重新将 RTF 转换为 DOCX，也不重建表格。原件缺失、损坏、版式未知或保存的分数分布与原图不一致时，预览与下载均返回 HTTP 409，并显示可操作的原因；不会静默替换为近似模板。

标准批语图 `gxufl_exam_review_checked.png` 和 `gxufl_exam_review_agreed.png` 是固定行楷排字资源，附有对应文字的图片替代说明；它们不是个人签名，也不产生签名授权。固定字形避免服务器没有楷体时改变标准批语外观。其他意见保留可编辑文字；既有手写批语章沿用已绑定图片。

分析正文保持原版填写区域的固定尺寸，按 12 pt 字号和原生单倍行距进行容量校验，最多容纳 8 行。建议正文先控制在 200 字左右，实际容量由中英文宽度、段落与换行决定，200 字不是硬性上限。正文过长时预览与下载明确返回 HTTP 400，提示精简后导出；已保存内容保留，不裁切正文、不缩小字体、不扩高表格或自动续页。审核意见同样校验原有填写区容量，超过 80 字或区域容量时要求精简。

验证覆盖意见保存/清空、旧材料兼容、失效绑定、批语章与个人签名分离、版本冲突、AI 重新生成后的版本，以及共享持久化与渲染器回归。原生文档契约还包括原件哈希与版式核验、预览和下载使用同一原件、详情不携带文件字节、23 行及末行注释保留、允许填写区域之外的 XML/媒体不变，以及超长内容明确拒绝导出。实际版面通过 DOCX→PDF/PNG 检查；不能用文件可打开或旧版自动跨页样例替代保真验证。
