# 试卷分析表审核意见与版式

试卷分析表使用 `department_review_opinion` 和 `dean_review_opinion` 保存两处独立审核意见。编辑卡片将意见放在对应签名点上方；确认签名同步保存本栏意见，整表保存保留两栏编辑结果。标准批语分别为“已核”和“同意”，支持最多80字的自定义意见及明确清空。

未签名、未修改的默认建议不会自动写入材料。旧材料仅在当前版本有有效个人签名、且没有已保存意见或批语章时补标准批语。个人签名和批语章分别解析：批语章位于意见区，个人签名位于签字区；批语章不能代替签名使材料变为完整。明确填写的文字或空值优先于批语章，避免重复显示。

详情、列表及导出均从当前材料版本的签名绑定解析状态；列表批量读取，避免每张卡片逐条查询。保存和重新生成使用材料版本及持久化快照校验，旧窗口不能覆盖较新内容。预览HTML禁止缓存，底层PDF及页面图片继续使用共享文档渲染器的内容哈希缓存。

DOCX保持原学校表格的A4、11列基础网格和正文最小高度，审核区合为两个完整单元格，取消内部横线，固定“意见在上、签名及签字标签在下”的顺序。两侧签字基线统一，单人和多人图片同时限制宽高并保留比例。底部备注移至表格外，恢复原表线宽、标题加粗和成绩图配色。

标准批语图 `gxufl_exam_review_checked.png` 和 `gxufl_exam_review_agreed.png` 是固定行楷排字资源，附有对应文字的图片替代说明；它们不是个人签名，也不产生签名授权。固定字形避免服务器没有楷体时改变标准批语外观。其他意见保留可编辑文字；既有手写批语章沿用已绑定图片。

分析正文使用可跨页的最小行高，竖标题改为逐字换行，解决LibreOffice在真正竖排单元格旁截断长文的问题。较长意见为两侧保留统一高度，防止签字错位。内容较长时自然续页，不通过缩小正文或裁剪内容强塞单页。

验证包含意见保存/清空、旧材料兼容、失效绑定、批语章与个人签名分离、版本冲突、AI重新生成后的版本、共享持久化与渲染器回归，以及真实Chrome桌面和手机交互。真实DOCX→LibreOffice→PDF/PNG核验覆盖空白、单侧签名、双侧签名、多人签名、80字意见及2204字正文；截图近似410字样例为1页，扩展539字样例为2页，2204字样例为3页，正文均完整保留。
