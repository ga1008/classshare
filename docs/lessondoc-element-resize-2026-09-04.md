# 学习文档元素缩放设计、施工与验收

## 问题与结果

原编辑器只有定位元素右下角的一个尺寸控制点，流式内容只有轮廓。普通定位元素改变的是外框尺寸，内容没有统一的固有尺寸，因而文字、按钮、HTML 等常表现为“改了宽高却没有缩放”。首页还缺少原来仅放在 `slides.css` 中的定位及编辑层样式。

此次改为八个缩放控制点：四角保持当前宽高比例；边中点只调整对应方向。旋转元素和组合内部元素使用逆变换计算指针位置，固定对侧边/角。转换后的流式元素保持原内容类型、ID、资源引用及动作，仍可继续编辑与交互，无需转成截图或静态 HTML。

## 模型和渲染合同

| 字段/场景 | 含义与规则 |
| --- | --- |
| `frame` | 沿用定位框；组合内部为父组合坐标，其余为 1280 × 720 画布坐标。 |
| `natural` | 内容的固有渲染宽高。普通定位元素第一次缩放时记录原框尺寸，后续缩放不反复修改此基准。组合沿用既有内部尺寸。 |
| `flowFrame` | 新的可选通用字段，结构与 `frame` 相同，但坐标相对于元素原流式占位。必须同时具有有效 `natural`；不能与 `frame` 共存，不能用于组合。 |
| 流式占位 | `.ld-flow-slot` 保留原位置和占位尺寸，内部使用同一定位渲染器缩放内容。缩放不会重排相邻内容；放大内容可能超出原占位，教师可移动、换版式或恢复自动排版。 |
| 固有尺寸边界 | 1—10,000；缩放框沿用 8—1,680 的尺寸和既有位置边界。超过单个框但在固有尺寸范围内的长内容等比缩小后启用控件。 |
| 嵌套容器 | 标签页、折叠详情、分步演示的内部内容由容器排版。子元素属性栏提供“选中外层容器”；容器可以整体转换、缩放，内部内容继续编辑。组合内部的定位元素可以直接缩放。 |
| 长文阅读模式 | 沿用原来的按内容顺序阅读，不施加画布定位或 `flowFrame`。 |

无需数据库迁移。新字段作为现有版本化文档 JSON 的一部分，使用原来的权限检查、校验、乐观锁、操作幂等、自动保存、草稿和历史版本。

`deck-engine.js` 的原生块渲染器仍负责全部 21 类内容。缩放只增加固定固有尺寸的包装层并应用二维缩放；图表结构、HTML 安全净化、播放器事件、测验答案、素材引用不另建一套逻辑。公共样式移入首页与课次都加载的 `course.css`，平台资源与样例包资源同步。

## 手势、反馈与性能

1. 选中定位元素或已转换的流式元素后，显示轮廓、八个小方框及独立旋转点。光标方向随元素与父组合旋转。
2. 从热区任意位置按下时，以原控制点和指针相对位移计算，避免刚拖动就跳变。
3. 四角默认锁定当前比例，无须按 Shift；四边中点改变单边，允许非等比拉伸。边界收窄到最小尺寸后停止，避免反转或负尺寸。
4. 常规控制点视觉尺寸约 10 CSS px、热区 24 CSS px。短文字等小元素按屏幕尺寸收缩热区，避免边中点被角点抢占；旋转点距顶边保持 28 CSS px。
5. `pointermove` 只记录最新指针，每个动画帧更新一次 DOM；不逐事件写模型、产生历史或发送保存请求。松开鼠标前刷新最后一次坐标，一个手势只提交一个撤销命令。
6. 首次缩放直接把当前内容 DOM 放入缩放包装层，保持拖动期间的内容节点。提交后使用既有页面增量渲染。
7. Esc、失焦、`pointercancel` 取消当前手势；文档已发生其他变化时取消旧手势，避免用过期坐标覆盖新模型。销毁时释放捕获并取消待执行动画帧。
8. 无额外尺寸缓动拖尾，保证内容跟手；沿用页面、选中状态及表单的既有过渡。

## 属性和跨功能衔接

- 流式内容属性栏显示“转换为可缩放元素”，转换后显示宽高、坐标、旋转、层级滑块及“恢复自动排版”。恢复保留内容及动作，移除固定尺寸约束，可撤销。
- 属性宽高滑块与画布缩放共用固有尺寸规则；旋转和层级未设置时按真实默认值 0 显示。
- 方向键移动使用对应的 `frame` 或 `flowFrame`，避免为流式元素误写第二个定位框。
- 内容结构表单排除 `flowFrame`，不向教师暴露内部坐标对象。
- 流式转自由画布/封面时根据真实占位及旋转尺寸转换到绝对框，并清除 `flowFrame`；已缩放的画布元素转流式时保留固有尺寸和显示大小。
- “我的元素”和跨课复制使用定位包装规范化尺寸，再按目标页面恢复合适的定位/流式形式。ID 重建及动作重映射继续走原有公共逻辑。
- 动作目标选择支持已转换的流式元素；原来的组合/拆组、全局元素及 HTML/AI 编辑规则保留。

## 施工顺序与代码分工

1. 核对入口 `index.js`、属性面板、控制器、几何计算、桥接、模型遍历、版式转换、组合、HTML 编辑；向下追踪原生渲染器、交互层、校验、模板和版本化保存。
2. 扩展 `geometry.js` 为八方向、固定对侧锚点的尺寸计算；新增 `resize_commands.js`，集中固有尺寸、转换、跨格式适配和最终命令提交。
3. 改造 `canvas_controller.js` 的控件绘制、光标、指针捕获、动画帧预览、最后坐标刷新与取消路径。
4. 扩展 `deck-engine.js` 与 `interact.js` 的流式占位、坐标测量和转换；把定位/缩放/编辑层基础样式移到公共 CSS。
5. 接入属性栏、方向键、插入、粘贴、模板、动作及版式转换；后端统一校验新字段，排除冲突状态。
6. 编写几何、模型、模板、保存与历史回归；真实浏览器逐类测试。修复实测发现的短文字热区重叠和旋转点间距问题。
7. 恢复隔离 QA 数据，生成设计及验收记录，明确暂存本次源码；从干净发布工作树运行 DryRun、正式部署、线上健康与静态文件字节核验，再推送 Git。
