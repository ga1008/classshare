# 教师课表查询与同步

入口：管理 → 教务 → 教师 → 课表查询，`/manage/academic/teachers/schedule`。
适用于已具有广西外国语学院有效组织身份及教务域权限的平台教师。

## 业务与数据边界

- 查询优先使用完整本地缓存；无完整查询覆盖时，使用当前教师自己的教务凭据同步后返回。
- 同步重新读取匹配教师及其完整学期课表，成功后原子发布，再返回结果。失败不覆盖旧数据。
- 学校、文本工号、规范学期构成快照身份；同名教师保留独立卡片。查询条件签名记录完整匹配范围，
  防止“本地已有一位同名教师”被误认为全部命中。合法零结果也可缓存。
- 每次至多匹配 20 位教师；超过时要求补全姓名、工号或增加筛选，不静默截断。
  上游读取串行并有请求间隔，同一上游账号用数据库租约互斥，不持有数据库事务等待网络。
- 账号关联仅使用同校、已验证且启用的教务凭据工号、活跃账号及有效组织成员关系。
  唯一候选显示已关联，多个候选显示待核实；不按姓名认领、不创建账号、不覆盖组织或授予权限。
  学院、职称、课程资料保存在来源目录与快照中，供后续身份功能扩展。
- 四张独立表保存目录、学期快照、查询覆盖、短期同步租约；不写平台课程、课堂、
  `class_offering_sessions` 或教师本人课表快照。
- 当前学期按校内学期日期选择；寒暑假保留最近已结束学期。缺少可用校历时使用日期兜底，
  课表仍按教务周次展示，不编造具体日期。

## 上游契约证据

2026-10-20 在用户已有登录的教师课表打印页，通过页面自身“查询”和“预览”动作观察网络：

| 用途 | 只读接口 | 关键输入或输出 |
|---|---|---|
| 查询页和真实选项 | `GET /kbdy/jskbdy_cxJskbdyIndex.html?gnmkdm=N214510&layout=default` | 学年、`xqm=3/12/16`，校区、部门、职称、外聘、开课学院 |
| 教师列表 | `POST /kbdy/jskbdy_cxJskbdyList.html?gnmkdm=N214510` | `jgh` 姓名或工号，`xnm/xqm`、分页；`items`、`totalCount/totalPage/currentPage` |
| 学期查看控制 | `POST /kbdy/bjkbdy_cxXnxqsfkz.html?gnmkdm=N214510` | 当前列表取得的教师标识及学期；`"false"` 表示未锁定 |
| 完整课表 | `POST /kbdy/jskbdy_cxJsKb.html?gnmkdm=N214510` | 本次列表的 `jgh_id`；`kbList`、`sjkList`、`bjsjkList`、`jxhjkcList` 等 |

稳定工号是 `jgh`，列表 `jgh_id` 是本次读取上下文中的不透明标识，不能用它替代工号。
课程包含课程号、教学班及组成班级、周次、节次、地点、校区、性质、人数、学分、
学时组成、考核方式等。未排时间课程保留完整来源描述，单独显示，不塞入虚构课次。
高级条件用于匹配教师；个人快照始终读取完整学期，不用过滤后的课程子集覆盖。
登录页、错误 JSON、分页缺失、重复工号、教师/学期不符和无法完整解析的课程均拒绝发布。
文档与提交中不保存凭据、Cookie、个人响应原文或会话标识。

## 界面合同

复用管理导航唯一源、LQ Field/Input/Dropdown/Button/Surface/Status/Dialog，
以及首页 `createScheduleDeck`。领域 CSS 仅负责布局、几何与数据排版。
教师大浮窗内按周展示 3D 课表，课次打开二级课程详情，未排时间课程也可查看详情。
`onLessonClick` 为可选共享回调；本页 `allowExpand:false` 避免多余第三层，原首页行为保留。
异步查询与详情均可取消，旧响应不能覆盖新筛选；弹窗焦点、Escape、滚动锁由 LQ 独占。
