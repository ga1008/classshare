# 玻璃界面布局与可读性修正

本记录涵盖本轮实现、本地验收及用户明确授权后的正式发布。

## 改动

- 共享页头统一以局部玻璃承载标题、副标题和操作；师生首页、通知中心、课堂班级信息在深色照片上保持可读，背景照片仍使用原有全屏高斯模糊。
- 通知中心改为概览、分类、搜索/阅读状态/批量操作三个清晰区域；手机按顺序折行，单条通知保持自然高度。输入框和筛选浮层使用共享玻璃参数。
- 教师课堂的列表、系别班级、课程视图恢复独立的标题、状态、操作区；修正窄卡内部仍使用三列布局导致逐字折行的问题。筛选与课表学期选择复用 LQ Selection。
- 学生首页的课表学期、课程集合学期/状态以及共享学期日历接入同一选择组件；修复隐藏原生选择器溢出、课程视图与重试按钮的旧样式覆盖 hidden 状态。
- 桌面侧栏默认展开，保留用户明确收缩的偏好；收缩立即生效，悬停不改变布局。搜索、展开/收起按钮使用统一玻璃控件。
- 原生按钮、操作链接、分段按钮及选择选项统一胶囊圆角。整张可点击内容卡片通过 `data-lq-shape="surface"` 保持卡片形状；卡内按钮仍为胶囊。
- 研讨消息使用头像、身份/时间、正文、操作区的自然排版；去掉每条消息外多余的白色整行底板。历史加载按钮、引用/有用/复制、输入工具统一玻璃控件。
- 修正较早历史批次插入顺序；保持加载前的阅读锚点。AI 完成消息不重复添加操作栏，广播与一对一分别检查。

## 模块边界

材质、状态、几何分别由共享 material、control-states、control-geometry 管理。页面 CSS 负责布局和密度；原生 select 继续保存值并派发原有 change 事件，LQ Selection 负责呈现、键盘及浮层生命周期。页头的 Python/Jinja、原生 JS 和 React 入口保持一致。

本次不修改数据库、权限、提交或评分 API。既有草稿、附件、表情、引用、私信等功能保留。
