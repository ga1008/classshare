# 材料签名流程：实现与验收

适用范围：成绩登记表、试卷分析表、考核计划表，共五个签名位置。对应设计见 `material-signature-workflow-improvement-plan-2026-09-08.md`。

## 使用方式

1. 在材料列表点击卡片空白处选择或取消选择。原有预览、编辑、下载按钮继续工作。
2. 右侧显示所选文档的共有属性和完成情况。同类型的本人文档可点击“申请签名”。
3. 每个位置使用同一个搜索多选组件：下拉内切换岗位身份筛选，选取个人签名或特殊签名，在“已选”中拖动或使用上下按钮排序。
4. 批量配置可以保留原有签名后追加，也可以替换为本次顺序。未配置的位置保持原状。
5. “已核”和“同意”可选，无需申请；它们不会替代必需的个人签名。自定义批语可留空，已有材料的历史显示规则继续兼容。
6. 提交后系统保存申请时的正式文档，并通知审批人。默认在一个位置全部获批后自动应用；关闭自动应用时，可在“我的申请”手动应用。
7. 独立菜单“我的资料 → 签名审批与使用”提供待我审批、我的申请、使用记录。可筛选文档类型、申请类别、申请人类别、任职身份、组织及关键词。
8. 点击申请后，右侧通过共享文档渲染器展示申请时材料；支持单项批准、本文件待我审批的全部签名、所选申请批量处理。本文件审批不受当前分页影响。
9. 选择文档后可打包下载，也可打包当前筛选下的全部文档。有待补充文档时，先列出完整名称，用户可取消，或明确继续把这些文档一起打包。

## 正式文档与权限

- 授权绑定具体材料、内容版本和签名位置，不跨文档复用。
- 每次申请保存不可变的 DOCX/XLSX 文档；首次预览生成的 PDF 另行保存，后续预览继续复用。审批页面、缓存图片和下载凭证均校验当前访问者的申请访问权限。
- 修改正文或重新同步教务原件会使旧申请失效；仅改变签名排版不改变正文版本。
- 签名图片发生变化时，旧图片的授权不能用于新图片；重新申请后的有效授权可以正常使用。
- 自动应用再次检查材料内容、原有签名顺序、签名图片和全部审批结果，并与正式材料更新在同一提交中落库。其他人或其他操作已经调整过该位置时，不覆盖现有结果。
- 修改自定义批语属于内容修改，应先在材料编辑器保存，再发起签名申请。特殊批语切换与个人签名排序不影响其他位置的正文授权。
- 试卷分析表沿用当前教务原件导出路径。原件缺失或损坏会给该文件返回明确错误，不静默换用其他模板。

## 后台处理与通知

- 新增材料批次、申请快照和临时压缩包表，以及现有签名流程的应用状态字段；迁移为增量添加，保留旧申请和使用记录。
- 复用现有持久任务队列处理批量申请、文档应用与打包。即使 AI 持久任务被关闭，材料任务仍有 worker 处理。
- 同一批次按文档保存处理结果，重试不会重新创建已提交文档的申请。失败文件保留原因，其他文件继续处理。
- 单次签名申请最多50份材料；单次打包最多200份；每个位置最多12个签名；审批操作最多50条。
- 打包使用正式文档导出服务，ZIP 中附逐份清单；临时压缩包七天过期，每日分批清理，审批快照保留用于审计。
- 批量申请按审批人合并消息。审批结果继续通过现有消息中心和邮件发件队列处理，遵循账号通知偏好、配额及失败重试。
- `signature_workflow` 已加入重要邮件通知类别。可通过 `SIGNATURE_NOTIFICATION_SENDER_TEACHER_ID` 指定已配置发信邮箱的统一发送账号；未指定时沿用原有教师发信配置。页面说明收件邮箱和发信配置的可用状态。
