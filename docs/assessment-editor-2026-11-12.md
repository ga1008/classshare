## 数据与业务合同

| 题型 | 存储标识 | 作答方式 |
| --- | --- | --- |
| 单选 | `radio` | 原生单选，选项数由题目决定 |
| 多选 | `checkbox` | 原生多选，兼容旧分隔字符串与数组 |
| 判断 | `boolean` | 与单选共用呈现，默认正确/错误，显示判断题提示 |
| 填空 | `text` | 新题按编号独立输入；无 `blanks` 的旧题保留单答案 |
| 简答 | `textarea` | Markdown 格式、编号与层级 |
| 分析 | `analysis` | 与简答相同编辑能力，保留独立类型 |
| 程序 | `code` | 格式编辑与可再次编辑的代码块 |
| 综合 | `comprehensive` | 格式、代码块与现有附件/绘图能力 |

统一词汇在 `classroom_app/services/assessment_question_contract.py` 和 `static/js/assessment_questions.js`。旧别名在读入时兼容，不批量重写数据库。

新填空的题干使用 `{{1}}`、`{{3}}` 等正整数编号（允许编号非连续），`blanks:[{id:"1",answer:"…"},{id:"3",answer:"…"}]` 是标准答案真值；顶层 `answer` 是同序数组镜像。添加、删除、手工修改题干编号同步对应编辑字段，其他编号的答案保留。旧填空只有明确选择“启用编号填空”才转换，不按逗号或分号猜测分隔。

学生收到的 `blanks` 仅含编号和提示，不能包含标准答案。学生草稿/交卷使用等长 `answer` 数组及 `blank_ids`，保留中间空字符串；空答案初始化兼容为全空数组。服务端拒绝缺位、嵌套对象和编号错配，且在附件写入前校验。完整试卷校验拒绝重复编号、缺少答案和题干编号不匹配。只有逐空精确匹配才固定满分；部分匹配、同义表达仍按评分细则处理。

试卷编辑、AI 出题配置与提示、JSON 导入、学生安全快照、草稿、提交、评分、教师批改展示、错题归集、导出、学情统计和小程序题型识别同步更新。沿用权限、已有答卷锁卷、试卷 revision、提交轮次、幂等和失败保留机制，不引入新表或新的后台任务。

## 编辑与渲染

`mountAssessmentEditor(textarea,{format,code,label})` 显式增强原生输入，返回 `refresh/destroy`；赋值恢复后刷新，重绘前销毁。原始 textarea 的 value/name/form 始终是提交及草稿真值。格式工具插入 Markdown，支持加粗、左/中/右对齐、自动编号、Enter 续号及 Tab/Shift+Tab 层级。空编号行退出列表，代码围栏内不续号，IME 组合期间不拦截键盘。

程序/综合题和教师题干可以插入代码：窗口复用 LQ Dialog/layer，代码高亮、语言启发式识别与手工切换、括号配对、自动闭合和四空格缩进均在本地完成。确认保存为 fenced Markdown；正文编辑区的代码卡显示内容摘要并支持再次打开，预览按原文顺序显示可编辑代码卡。取消不改正文，未确认代码通过 Escape 关闭时会提示，刷新/离页则由共享 DirtyGuard 提醒；层退出解除 inert 后再写回，避免将正文误插入弹窗。

`attachAutosize` 默认两行、单行文字上下居中，增长至 16 行后内部滚动；代码窗口同样遵循两行起步、16 行上限。只增强显式挂载节点，窗口共用一个 resize 监听，没有全站扫描或常驻动画循环。代码超过 100 KB 时高亮降级为安全纯文本，不截断作答。语言识别是编辑辅助，不编译或运行代码。

`renderAssessmentMarkdown` 复用现有 MarkdownRuntime 清洗，另外处理受限的 `:::align left|center|right` 语法和转义后的代码标记。只读视图使用同一渲染，防止教师与学生看到不同文本。没有增加第三方包。

交叉审查补充：题号在学生 HTML 属性中统一转义；新建试卷成功立即采纳服务器 ID/版本并使用 PUT 续存，保存请求期间继续编辑不会被跳转丢弃或锁死按钮；代码高亮采用只前进的词元扫描，未闭合块注释不会反复回溯。

小程序同步八题型、逐空输入/恢复及答案展示。其程序题保留 Markdown 原文编辑；网页端提供完整的代码块高亮编辑，未宣称微信真机已通过视觉验收。
