## 阅读交互的实施决定

用户要求的是省去材料列表或确认步骤。单份材料直接打开现有阅读页的新标签，原课堂的课次详情、聊天、附件和连接保持原样；点击阅读页“返回”关闭阅读标签。多份仍使用原材料列表，返回后留在该列表，再关闭回详情。没有另造材料渲染器，也没有修改阅读归因。

为保证这次打开属于浏览器认可的同步用户操作，完整可访问材料集合改在**打开课次详情时**读取一次；这是对旧计划“点击材料入口才读取”的明确调整。拖动和焦点浏览不预取，整学期不预载，不触发简介AI生成。集合结果携带给多份列表，不二次请求；加载中入口busy，失败可重试，0份直接显示准确空态。关闭/快速切换依靠Abort与代次检查防止旧响应写入新课次。每个请求内缓存重复材料授权结果，下一请求重新鉴权。

完整授权校验包含绑定源、HTML包根与实际入口。读集合后撤权/删除的情况仍由原reader再校验，并提供局部错误与经过验证的课堂返回；不以绑定关系或可点击URL代替权限。

## 首屏稳定性

最终检查发现并修复两处实际加载跳动：学生课表空host没有预留挂载后的画布高度；课堂任务SSR只有加载文字，React接管真实任务卡片后将活动区推下。现在课表首屏与挂载后共用420px/窄容器360px画布变量；课堂首屏用已有授权任务集合生成真实卡片、状态、个人截止与筛选计数，不增加数据库查询，由React原子接管。新增4项SSR投影测试，防止短暂出现已关闭提交入口或与教师批改顺序不一致。

`layout-before.json`与`layout-after.json`在相同合成库、正常动画、1024/390/320px、学生/教师首页和课堂共12个页面组合记录LayoutShift来源。修复后学生首页CLS分别为0.0056/0.0205/0.0196，教师课堂为0.0017/0.0012/0.0015；12项最大值0.0319，均低于计划0.1目标。这里采用无近期输入的累计LayoutShift值；没有禁用动画或隐藏内容来降低结果。

`current`为真实应用的35张截图：学生/教师首页与课堂的六种宽度、博客参考、五套课堂配色、两种详情宽度、真实reader、材料列表及作业历史。截图使用减少动态设置以稳定取景；动画与滚轮另由正常动态交互用例和上述加载测量验证。基线来自起始提交的隔离副本，保留9张参考截图；最终库额外进行了合成提交/待办/消息交互，不将两批截图的所有业务计数宣称为完全同状态对照。

最终截图采集的25个主页面组合全部HTTP 200、零页面异常、零横向溢出；本机取景测量LCP 76–280ms、最大CLS 0.0319。两种截图宽度下，课次材料按钮实际为130×36px；触控媒体规则将命中高度调整为44px。主按钮与“返回课次”均按内容宽排列。
