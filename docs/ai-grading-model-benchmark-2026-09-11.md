## 结论

1. **豆包 2.1 pro** 最接近人工基准（总分 MAE 3.9，主观题单题 MAE 1.0），但单份 200–300 s、约 0.49 元，7 份合计 3.4 元；对跨文件矛盾的检出弱于 DeepSeek。
2. **DeepSeek 4.1 flash（deepseek-flash，思考 max）** 速度 6–8 倍于豆包 pro，费用约 1/5（0.09 元/份），对证据冲突（口令不一致、传错文件、截图非本人、地址写反）检出最全，且会主动置 needs_review。缺点：对"截图齐但文字空"的上机题偏宽松（4310 给 82–89 vs 人工 73）；格式纪律差，19 次调用中 4 次触发结果校验（缺 evaluation、summary 超 120 字、缺 summary），线上有一次修复重试可兜底但会翻倍耗时；**思考 max + 16k 输出上限在 18 张图时把 16384 token 全部耗在思考上、正文为空**，需把 max_tokens 提到 32k 或改 effort=high。
3. **豆包 2.0 lite** 便宜（0.03 元/份）但不可信：空文字上机题给 98、Web 期末给 80、伪造证据的 1575 给 91，几乎不报冲突。
4. GLM-4.6v / 4.6v-flash 系统性高估 15–25 分，看不出跨文件矛盾；qwen3.7-plus 偏严且不稳定（4293 给 20），qwen3.6-flash 出现"图片没上传"的幻觉给 0 分。
5. 建议：批改主模型改为 deepseek-flash（effort=high 或 max+32k 输出），保留豆包 pro 作为 needs_review/低置信度时的仲裁；同时修正代码里的 DeepSeek 价表。
