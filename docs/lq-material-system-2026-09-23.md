# 全站共享玻璃材质与接入契约

本次按用户提供的 iOS 截图统一所有交互表面，覆盖内容面板，不再沿用旧设计稿“内容必须是不透明纸面”的限制。白板笔迹、签章、试卷打印预览和正式导出是内容数据，保留原色与纸张语义。

## 模块化的边界

1. `static/css/lq/tokens.css` 是基色、透明度、圆角、模糊、层级和时长的唯一参数来源，浅深主题都由同一套语义名解析。
2. `materials.css` 定义五档材质和公共属性接口；`components/material-boundaries.css` 决定如何渲染霜面及如何降级。页面不复制模糊算法。
3. Jinja 宏、原生 JS 工厂和 React 组件继续共享 `lq-*` 组件；菜单、对话框和抽屉使用现有 LQ layer 管理 portal、焦点、Escape 和滚动锁，不新增第二套协调器。
4. 页面 CSS 只保留尺寸、布局、密度和业务状态；独立考试、编辑器、批改、课堂与简历均明确接入材质。新增页面声明属性即可，无需修改共享模块内的页面名单，也不使用 MutationObserver 遍历业务 DOM。
5. 模板、数据与业务控制器保持边界。此次不会重写草稿、提交轮次、权限或评分 API；对明确的交卷重复请求增加控制器防重入。每个业务修复保留专门回归证据。

## 五档材质

| 属性值 | 用途 | 浅/深基色不透明度 | 模糊策略 |
|---|---|---|---|
| `clear` | 有独立对比保护的图片浮层 | 22% / 22% | 16px；低能力设备升为厚材质 |
| `control` | 独立按钮、输入、选择、胶囊 | 44% / 44% | 使用承载层的霜面，不逐控件创建过滤层 |
| `chrome` | 顶栏、侧栏、操作条 | 46% / 46% | 16px，实时模糊其下滚动内容 |
| `content` | 题干、列表承载区、卡片组 | 50% / 50% | 透视统一的全屏高斯背景；不另铺图或创建过滤层 |
| `raised` | 弹窗、下拉、抽屉 | 58% / 58% | 24px，实时模糊页面内容 |

浅色基色为白色，深色为 `224 30% 12%`。语义状态颜色只调整色调，不能把危险操作、保存失败、零分或只读状态装饰掉。内容字号、行距和对比优先。

场景承载区用 `data-lq-tone="light|dark"` 选择同一组配对参数：38% 基色、16px 模糊、对应正文/次要文字以及 22% 内嵌控件色。师生登录使用相同配方，不再叠加 80% 黑色遮罩。普通玻璃承载区内的控件使用 20% 白色/6% 白色薄填充，减少嵌套叠色。共享接口为 `--lq-material-fill/ink/muted` 和 `--lq-control-fill/ink`；页面不得写死白字或增加第二层遮罩。

`components/control-states.css` 统一原生、Jinja、React 和保留入口的按下、选中、展开、聚焦、加载与禁用。色对在同一帧切换，动画只处理位移、边框和阴影；加载保留按钮文案，不能用透明文字冒充 spinner。危险动作继续使用危险语义色对。

```html
<section data-lq-material="content" aria-labelledby="task-title">
  <h2 id="task-title">本周任务</h2>
  <!-- 使用现有按钮组件；行和按钮不再独立创建模糊边界 -->
</section>
```

重复数据列表把材质放在承载区；不能在每条数据上创建新的模糊边界。浮动菜单交给共享 layer 移出祖先的过滤/裁剪上下文。直接使用 `data-lq-interactive` 的可操作材质遵守统一 hover、press、focus；禁用态不抬升，触屏不保留悬停光晕。

布局容器不等于材质表面：已有面板内的按钮排版层、卡片列表、卡片正文和页脚不再添加 `lq-surface`、`lq-list` 或 `data-lq-material`。桌面顶栏的 inline pane 保持透明，打开手机抽屉时才由共享 Shell 控制器添加玻璃；侧边栏材质放在内部圆角表面，SSR 与增强后的所有者一致。响应式折叠区的桌面展开形态、弹窗内嵌日历明确使用外层面板，关闭玻璃及低能力退路也不能给布局壳重新填色。高对比模式仍保留日历的辅助轮廓。

## 背景与性能

所有 8 个用户文档根共用 `partials/lq_page_backdrop.html` 和 `page_backdrop.js`，每页只出现一次。背景复用开屏欢迎页图库与账号偏好，固定铺满视口，`cover` 保持比例并居中裁切。登录、欢迎和页面保持同一视口裁切；欢迎结束时全屏清晰图淡出，露出同一张图的高斯背景，绝不收缩到顶栏。

页面全屏背景使用预生成高斯图，缺少衍生图时才给单个原图施加 24px 模糊并扩展边缘。`--ls-scene-opacity` 统一控制浅色 50% / 深色 38% 的背景强度，作为玻璃文字对比测试的真实边界。内容面板只负责薄填充和边缘高光，不在面板内重复画固定背景。桌面和触屏共用该模型。

外观设置支持跟随欢迎场景、按类别选图、图库指定图片和纯色。指定图用既有 `backdrop` 字段的 `image:<filename>` 保存，只接受服务器图库白名单；不接收任意 URL，不新增数据库结构。偏好继续走账号 context 与版本 CAS，图库按需展开和加载，跨页背景交接按账号隔离。

入场只改变背景 opacity，保持照片位置和大小。不循环播放、不常驻 `will-change`。内容内的嵌套面板和控件禁止叠加 blur，数据增长不会增加列表行的过滤层。真正浮起的导航/菜单使用实时模糊，不能拿背景贴图遮盖正文来冒充透视。

无 JS、低能力、关闭透明、减少透明、高对比、强制配色和打印都有可读退路；不能要求浏览器识别一个可选媒体特性才启用正常材质。减少动效时取消入场与位移。图库请求失败不影响正文、提交或导航。
