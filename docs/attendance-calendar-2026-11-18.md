# 本学期出勤日历与智慧课堂同步

教师进入课堂的「签到统计 → 学期出勤日历」，默认看到本课程全班的月历。「统计对象」可切换到某名学生。从「学生汇总 → 查看个人课次 → 个人出勤日历」也能进入同一份记录。从某一节课的学生名单进入个人课次时，会展开该生整个学期。

## 查出勤与改签

- 月历按实际日期、节次排列，保留周末、已有校历节假日和经过核对的调课信息。同一天上两次课时，打开日期后选择具体课次。
- 全班格中的到场人数包含正常出勤、迟到和早退，未到人数包含缺课、病假和事假。只有应考勤学生全部正常出勤才算满勤。待确认和免考勤单列。原课程出勤率继续使用「正常出勤人次 ÷ 已确认应考勤人次」。
- 点日期，勾选学生或选择全部可改学生，选状态，填理由。「保存到本地」记录本次决定。「保存并推送」保存后立即核对本课刚改动的学生，并展示待推送差异。
- 已上课但没有本地点名时，可人工补记。系统建立课次名册、记录修改人和理由，其余学生保留待确认或免考勤。之前已收到的学校回读、已确认 PDF 和申诉更正仍有各自来源。一个人同一课次只计一次。
- 多人同时改动同一记录，或浮窗打开后该课改了日期、节次，保存时会提示冲突并保留草稿。刷新后可核对最新时间和名单，再决定是否保存。

## 选择同步范围

| 教师要处理的范围 | 操作 |
| --- | --- |
| 一人一课次 | 打开个人日历中的一个日期，在课次详情同步或保存并推送 |
| 一人多课次 | 从个人日历打开智慧课堂同步，选择课次 |
| 多人一课次 | 从全班日历进入课次详情，可选部分学生或全班 |
| 多人多课次 | 从全班日历打开智慧课堂同步，同时选定课次与学生，或选「每课全班名单」 |

每个课次使用自己的历史名册、学校课次和点名轮次。预览列出每课可写、已一致和需核对的学生。教师确认后，后台仅按已核对的目标执行。已提交任务可在近期回执中查看。

如需新建学校点名，先选「每课全班名单」，核对预览后逐课勾选「为本课全班新建学校点名」。点击定位按钮，核对课次清单并授权本次浏览器定位。单人或部分学生可以更新已有学校点名。若另一位教师已在学校发起点名，系统会停止该课的创建并提示重新预览。

## 两端怎样对齐

先确定学校学期、课程和授课班，再对齐日期、教学周与节次，最后按确切学号比对学生。审核过的调课关系会复用。候选有歧义或名单发生变化时，可打开「核对此课对齐」，比较候选并确认。班级人数相近、课程名称相似或同一天有课，均不足以证明属于同一次点名。

| 本地 | 智慧课堂 | 同步处理 |
| --- | --- | --- |
| 未点名 | 未点名 | 保留未点名，该课次不产生缺勤 |
| 未点名 | 已点名 | 读取并保存学校来源，供本地统计使用 |
| 已点名 | 未点名 | 保留本地结果。创建学校点名以学校开放、教师明确授权和本次浏览器定位为前提 |
| 已点名 | 已点名 | 在准确轮次内逐人比较、推送已确认差异并回读。学校点名仍进行中或本地尚未结算时等待 |

学校较新的改签、请假与其他特殊状态有专门的保护规则。需要人工裁决的记录在预览中说明原因，可进入单人详情核对学校现值。发送后断线或回包不确定时，查看本次回执并回读学校。学校回读一致才显示确认。
