# 课次生命周期与知识树（2026-10-17）

## 1. 解决的问题

课次原先只按日期推进（往期/当前/下一次），无法表达"一次课没讲完、拆成两次"、"讲完还多讲了后续"、"两个班进度不同"。现在每个课次拥有**独立生命周期**，进度由教师勾选的知识点计算，与日期解耦：

- 生命周期：`none`（未生成知识树）→ `not_started`（0%）→ `in_progress` → `completed`（100%）。
- 课次属于 `class_offering_sessions`，每个开课班级的课次是独立行，所以两个班同上一门课时进度天然分开，互不混淆。
- 日期派生的 `progress_state`（往期/当前）保持不变，供课次导航定位；知识树进度是附加的第二个维度。

## 2. 业务闭环

1. 课次绑定学习材料（主绑定 `learning_material_id` 或材料绑定表）后，课次详情浮窗出现「知识树」入口；未绑定时教师入口禁用并提示。
2. 教师点击「生成知识树」：后端建/取 `session_knowledge_trees` 行、写生成令牌，走 durable job（`AI_DURABLE_JOBS_ENABLED`）或进程内任务。AI 输入：课程简介、教材简介与目录、课次标题/说明、前后课次标题、上一课次未完成的末梢、本课次全部 Markdown/HTML 学习文档正文（最多 18k 字）。
3. 服务端归一化（`normalize_tree`）：顶层 1–4 个大知识点；整棵树 2–3 层（超过三层的部分并入第三层的说明；全是单层直接判失败；个别无下级的大知识点补一个同名基础单元）；末梢最多 40 个；末梢比重按 AI 给的重要度归一化为**整数且合计恰为 100**，每个至少 1。
4. 教师点末梢左侧圆圈（或聚焦后按空格）= 切换完成；点节点其余位置 = 在右侧栏显示该节点详情（第四轮起拆开：单击既切换又选中会让“选中后编辑/删除”误改进度）（详细介绍、案例、思考、前置/后续关联、上下级与前后同级）。进度 = 已完成末梢比重之和；全部末梢完成才算 100%（`completed_at` 记录完成时间）。
5. 「全部完成 / 全部取消」批量写入；同级节点按住拖动（或侧栏上移/下移）调整顺序，节点 id 稳定，完成记录不受影响。
6. 文档更新检测：生成时记录绑定材料的指纹（材料 id + 实际文本文件 id + `file_hash`）。之后 git 重新下载、手动编辑或改绑材料都会改变指纹，教师打开知识树时「重新生成」高亮并提示。
7. 重新生成会**整体替换知识树并清空完成记录**（确认框说明将清空的百分比）。生成失败保留旧树和旧进度并显示错误；生成中锁定勾选/排序（409）。
8. 课堂页课次卡片、「全部课次」列表、详情入口按钮显示简要进度（环形 + 百分比，颜色区分：灰=未开始，琥珀=进行中，绿色 ✓=已完成）。弹窗内操作实时回写卡片。
9. 学生：本课堂学生可只读查看已生成的知识树与进度（无生成/勾选/排序），写接口对学生 403。

## 2.1 生成质量（第三轮）

- 提示词真源 `classroom_app/services/session_knowledge_tree_prompts.py`：硬性结构规则、基础单元粒度（5–20 分钟可讲完、可判定讲完/未讲）、比重评分细则（核心 14–30 / 常规 6–12 / 铺垫 2–5）、标签与字段写法、空泛标签禁用表、练习/实验的归属规则、上一课未讲完内容的处理，以及一个**完整示例**（数据结构“栈与队列”的输入摘要 + 标准输出，11 个单元比重合计 100）和输出前自检清单。示例由 Python 字典生成，单元测试保证示例本身零质量问题且归一化后比重不变。
- `quality_issues` 在归一化前检查原始输出（顶层数、层数、单下级节点、单元过少/过多、重复/空泛标签、缺比重、比重全相同、缺 detail）；有问题时把问题清单和上一次输出反馈给模型**重写一次**，取问题更少的一份，再走 `normalize_tree` 兜底。
- 比重归一化改为按比例的最大余数法：AI 已给出合计 100 的比重时原样保留，任何单元至少 1。

## 2.2 文档与知识树（批量管理，第三轮）

- 入口：课堂页「课次导航」标题栏的「文档与知识树」（仅教师）。浮窗列出全部有效课次：课次/标题/日期、绑定的学习文档（可新标签打开）、知识树状态（未绑定文档/未生成/生成中/生成失败/文档已更新/未开始/进行中/已完成）、进度环与 已完成/单元数、失败原因。
- 顶部汇总：课次数、已绑定文档、已生成、未生成、需更新、生成中、已完成、平均完成度；筛选：全部/未生成/需更新/生成中/失败/未绑定文档/已完成。
- 批量：「一键生成未生成的」（只处理已绑定文档且无树的课次）、「重新生成文档已更新的」、「全部重新生成」（确认框写明将清零进度的课次数）。后端 `POST /api/classrooms/{offering}/knowledge-trees/generate {mode: missing|stale|all}` 在一个事务里逐课入队（durable job；未启用 durable 时进程内信号量限 2 并发），跳过生成中/未绑定的课次并返回原因，单次上限 80。
- 单课：生成/重新生成（有进度时确认）、查看知识树（嵌套打开单课知识树浮窗，期间冻结管理列表以保持触发按钮，关闭后刷新）、前往课次（关闭管理浮窗后打开该课次详情，用于绑定/更换文档）。
- 生成中每 4 秒轮询，结束时提示成功/失败数；每次刷新把进度回写到课堂页课次卡片。

## 2.3 大树性能（第三轮）

- 各节点完成比重一次后序遍历算出（原先逐节点递归为 O(n²)）；折叠计数缓存；SVG 连线每棵树只创建一次，重绘只改 `d` 与状态类；Ctrl+滚轮缩放按帧合并；状态比较先比版本号；画布/节点 CSS containment（**连线 SVG 不能加 `contain: strict`**：尺寸包含会把 SVG 压成 0 高并裁掉全部连线，第四轮修复“上下层连线丢失”即此因）；管理列表行 `content-visibility: auto`。

## 2.4 手动编辑与拖动（第四轮，2026-10-18）

规则真源 `classroom_app/services/session_knowledge_tree_edit_service.py`，前端 `static/js/knowledge_tree/model.js` 同规则乐观预演，最终以服务端返回为准。

- **新增**（侧栏「添加下级 / 添加同级 / 添加大知识点」，或选中节点按 **Tab**）：新节点总是新末梢，创建后自动选中并进入侧栏编辑、名称全选。父节点原是末梢 → 新节点**继承**其比重与完成状态（父节点被细分，总比重不变，提示一次）；父节点是中间节点 → 新末梢先补足合计与 100 的差额，已满 100 时取现有末梢平均比重（合计超过 100，出现提示）。第三层节点按 Tab 改为添加同级（最多三层）。上限：大知识点 8、同级 12、全树 160 个节点。
- **修改**（侧栏「编辑内容」、**F2** 或双击节点）：名称（必填，≤40）与详细介绍/案例/思考/前置/后续；根节点编辑课次主题与概述。名称框 Enter 保存、Esc 取消；切换选中、关闭浮窗或开始生成前自动保存正在编辑的内容；后台响应不会重建正在输入的表单。
- **比重**：选中末梢，侧栏数字框（0–100 整数）修改后自动保存；侧栏与工具栏显示「比重合计 N%」，≠100 时为警示并提供「按比例调整为 100%」。进度 = 已完成比重 ÷ 比重合计（合计恰为 100 时与原规则完全一致；全为 0 时按单元个数）。
- **删除**（侧栏「删除」或 **Delete/Backspace**，必须确认）：确认框写明删除范围（下级个数、基础单元数、比重合计、已完成数）与删除后的比重合计。删除中间节点连同下级；父节点因此没有下级时重新成为末梢并**承接**被删比重（被删末梢全部完成才算完成），合计不变；根节点与最后一个大知识点不可删。
- **拖动**：除根节点外任意节点都能拖。鼠标/笔按下移动 5px 即拿起，触屏长按 320ms；层级保持不变，可放到同层任意中间节点之下（大知识点在根下重排）。拿起时节点放大、投影加深、随速度轻微倾斜，连线跟着节点伸缩；其余节点按“若在此放下”的预览布局用弹簧让位；靠近画布边缘自动滚动。拖大节点（有下级的节点）时同层节点先收起为 `+N`，放下后先落位、再重新计算布局并展开。原父节点被拖空时成为比重 0 的末梢。键盘替代：**Alt+↑/↓**（由下向上时 Alt+←/→）或侧栏上移/下移。
- **配色**：每套主题 8 种分支色（墨线改为八种墨色，不再全黑）；大知识点底色、细分知识底色与末梢边框按分支色分层着色。大知识点首次编辑前把颜色序号 `tone` 固定进树里，之后重排不换色；新增大知识点取未用颜色。
- **动效**：节点位置由阻尼弹簧驱动（ζ≈0.87，轻微回弹），节点、连线与折叠圆点在同一帧读同一组位置，连线不再与节点脱节；节点按 id 增量对账，**不再整树重建**（原来每次服务端响应都重建全部节点，节点从左上角飞回——即“点击就全局抖动”的根因）；首次侧栏展开不再让画布重新居中（偏移保持，改为可滚动），并关闭原生 scroll anchoring。只随操作而动：按压轻压缩（LQ press 令牌）、勾选圆圈弹一下并描出对勾、新节点从父节点圆点长出、删除节点缩回父节点、完成比重条渐变。reduced-motion / `data-lq-motion=off` 直接落位。
- 重新生成会清空完成进度和手动编辑过的内容（确认框写明）。

## 3. 并发与一致性

- 勾选/批量：`version` 乐观并发，服务端最多重试 4 次；前端串行队列，只应用最后一次响应，失败时回读服务端真值。
- 排序：服务端校验同级集合完全一致，否则 409；不要求客户端版本号（排在勾选后面的排序请求不会误报冲突）。
- 编辑（第四轮）：增删改移与比重归一化都按节点 id 在最新行上重放（`edit_tree`，version 乐观并发、重试 4 次），完成记录只保留仍存在的末梢；生成中一律 409。
- 生成：`ai_gen_task_id` 令牌守护，旧任务结果不会覆盖新一轮；生成超过 20 分钟视为卡死，读取时转为失败并清空令牌，迟到结果被丢弃；前端轮询上限 22 分钟。
- durable worker：`_knowledge_tree_outcome` 把业务已记录的失败或被取代的令牌视为任务完成，不进入重试循环。
- 课堂页读取进度用 `best_effort` 保存点包裹：知识树表异常不会拖垮课堂页事务。

## 4. 接口

前缀 `/api/classrooms/{offering}/sessions/{session}/knowledge-tree`

| 方法 | 子路径 | 角色 | 说明 |
|---|---|---|---|
| GET | （无） | 教师/本班学生 | 状态、树、完成 id、进度、生命周期、`is_stale`（仅教师） |
| POST | `/generate` | 教师 | 开始生成（未绑定材料 400，生成中 409） |
| POST | `/leaves/{leaf_id}` | 教师 | `{done}` 切换末梢 |
| POST | `/bulk` | 教师 | `{done}` 全部完成/全部取消 |
| PUT | `/order` | 教师 | `{parent_id, order[]}` 同级排序（保留兼容，前端改用 move） |
| POST | `/nodes` | 教师 | `{parent_id, label?, index?}` 新增末梢，返回 `created_id`；`parent_id` 空或 `__root` = 大知识点 |
| PATCH | `/nodes/{id}` | 教师 | `{label?, detail?, example?, question?, prerequisite?, extension?, weight?}`；`__root` 改课次主题/概述；比重只对末梢 |
| DELETE | `/nodes/{id}` | 教师 | 删除节点及其下级（根与最后一个大知识点不可删） |
| POST | `/nodes/{id}/move` | 教师 | `{parent_id, index}` 同层换父节点或换位置 |
| POST | `/weights/normalize` | 教师 | 按现有比例把末梢比重调整为合计 100 |

班级级：`GET /api/classrooms/{offering}/knowledge-trees`（全部课次文档与知识树状态，教师）；`POST /api/classrooms/{offering}/knowledge-trees/generate`（批量生成）。

## 5. 前端与组件合同记录

- 来源与 owner：`static/js/session_knowledge_tree.js`（唯一控制器），入口在 `static/js/classroom_page.js` 的课次详情；样式 `static/css/session_knowledge_tree.css`。
- 共享组件：LQ Dialog（`createDialog/openDialog`，size `full`，持有层级/焦点/关闭/滚动锁）、`createDomainButton`、原生 select + 共享 Dropdown、`createComponent('progress', {variant:'ring'})`、`chip`、`spinner`、`createStatus('alert')`、`confirm`。
- 内容槽：画布（`adoptDomainContentSlot`）承载节点、SVG 连线与五套主题数据配色（玻璃/墨线/彩带/蓝图/暖纸，均为底色+前景成对）。工具栏控件不自绘材质。
- 视图偏好（方向 由左向右/由下向上、主题）存本机 `localStorage`，不宣称跨设备同步。首次打开自动适应（最小 75%）。
- 画布操作（第二轮）：普通滚轮上下滚动（Shift+滚轮横向，浏览器原生）；Ctrl+滚轮/触控板捏合以光标为锚点缩放，并拦截浏览器页面缩放；画布获焦时 `+`/`-` 缩放、`0` 适应；双击空白处适应；鼠标/笔按住空白处拖动平移（触屏用原生滑动；滚动条区域不劫持）。
- 折叠：每个有下级的节点在连线出发点（左→右为右缘中点，下→上为上缘中点）有圆点按钮，点击收起/展开该节点全部下层；收起后显示 `+N`（隐藏的下层数），子树动画收回圆点。工具栏「全部展开 / 只看大知识点」。折叠状态按课次存 `localStorage`（重新生成后自动剔除失效 id），展开/收起时锚定被点节点在屏幕上的位置；侧栏跳转到被收起的节点会自动展开其祖先；方向键"进入下级"遇到已收起节点时先展开。
- 缩放与字体：整块画布用 transform 等比缩放，文字、边框、圆点与连线一起缩放；每个节点挂 ResizeObserver，字体加载、主题切换、浏览器缩放等导致节点尺寸变化时自动重新测量与布局，避免文字溢出或节点相互重叠（"穿模"）。
- 状态：加载、未绑定材料、无树、生成中、生成失败、文档已更新、进行中、已完成、学生只读、无权限（403）。
- 键盘：节点为原生 button（treeitem），方向键沿父/子/兄弟移动焦点，Enter/Space 切换或查看；侧栏上移/下移替代拖动。reduced-motion / `data-lq-motion=off` 关闭节点过渡，forced-colors 有回退。

- 第四轮证据（P03 合成运行环境 + 正式静态构建 + mock AI，脚本 `.codex-temp/kt/verify5.mjs`、`verify6.mjs`）：连线 19/19 绘制（左→右与下→上）；五主题大知识点颜色互异且随主题变化；点选与勾选时 20 个节点位移 0、节点元素不重建；Tab 新增并进入编辑、Enter 保存；比重改 30 → 合计 130% 提示 → 一键归一化 100%；末梢跨父节点拖动持久化；大知识点拖动时同层收起 17 个节点、放下后重排并全部展开、颜色不变；Alt+↓ 重排；Delete 删除末梢与整枝（确认文案含比重合计）；F2 改课次主题；刷新后持久化；学生无编辑入口、5 个新写接口均 403；390 宽移动端侧栏编辑；reduced-motion 正常；控制台零错误。
