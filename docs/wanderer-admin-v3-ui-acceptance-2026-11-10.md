# 散修管理工作区改进与界面验收（2026-11-10）

本轮将管理工作区的标题、管理入口与标签页保持在固定位置。桌面会话列表和聊天原文分别滚动；窄屏在列表与原文之间切换。原管理操作、人格/头像/境界/寿元等表单、执行核对入口和保留账本继续通过既有接口工作。

## 功能与合同

- `wanderer_conversation_view.js` 只读管理员原文，显示发言方向、选中会话、真实未读值（接口没有则不伪造），复用社交时间解析显示本地时间。会话列表有独立页码，消息通过 `before_id` 继续加载更早记录并保持阅读位置；回到最新明确刷新。仅合并相同消息 ID 的分页重叠，相同内容的不同 ID 仍完整显示，方便核查重复发送。
- `wanderer_workspace.js` 展示本人对其他成员、其他散修对本人的双向排行和具体分值。后端决定排序、评分与权限；不制造真人的反向好感。五档评分标签、版本、理由与完整记录可见。基础概况展示每日免费自省余额；关系页用紧凑摘要，将排行保留在首屏。
- `wanderer_memory_editor.js` 提供当前有效原文、修改内容、必填理由与前后对照历史。请求包含版本、内容哈希和稳定请求编号；409 与网络失败保留草稿，重新读取后仍须人工比较再保存。草稿跨分区与详情关闭保留在当前页面，不写浏览器持久存储。保存中字段只读，LQ 层否决关闭；离开页面时保护尚未保存的草稿。原文与可见范围由后端保护。
- 身份分区动态读取后端白名单，原 42 类账本加免费自省会话、自省请求计次、每日好感评分、评分提交回执、消息送达回执、管理员记忆修订，共 48 类。新类别均有中文名称。
- 按钮、选择卡、气泡、卡片、标签、进度和折叠均复用 LQ。领域 CSS 仅布局、尺寸、排版和共享材质文字色；没有新增私有表面、动效或模糊层。主题与减少动画偏好由共享组件负责。
