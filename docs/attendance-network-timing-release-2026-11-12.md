## 交付行为

- 修复旧规则要求全班形成密集时间峰、导致已有服务器接入记录仍全部待确认的问题。新轮按每名学生在实际记录窗口内的服务器证据判断，记录期间即可显示出勤。
- 新增可选 IP 限定；默认关闭。开启后展开一行一个的网段输入，建议教师连接网段；关闭后保留已保存的网段配置，但不以 IP 阻挡判定。
- 教师点击开始时，以服务器时间建立实际窗口；临时补课、调课不受原课表日期限制。实际窗口与智慧课堂课次绑定身份分别保留。
- 显示已上课时间、普通结束后的补报倒计时、后台处理阶段及立即结算进度。重启结算需要确认，旧任务不能回写新代次结果。
- 学生卡片支持状态筛选、姓名/学号搜索、登录跨度和学习时长排序；未知时长置后，保留改签草稿。
- 同时发布此前已完成本地审查的单人“保存／保存并推送”和立即结算。单人推送仍受课次已对齐、学校已开始点名以及远程未知请求保护约束。

旧轮不会因部署或刷新自动变更规则。教师对旧的全班待确认轮次点击“立即结算”，确认采用新规则后，系统沿用原记录窗口和原 IP 限定重新计算；人工改签保持。没有接入证据或仍不符合原 IP 限定的学生不会被无依据改为出勤。
