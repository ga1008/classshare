# 液态玻璃第二轮修订

本轮针对用户实际截图中的背景收缩、登录灰色实心卡、菜单不透明、按钮文字消失以及各入口材质不一致进行修订。前次发布记录保留在 `lq-release-acceptance-2026-09-23.md`；本文件只记录新增变更与本轮证据。

## 行为与模块

- `page_backdrop.js` 是单个文档的背景所有者。欢迎清晰图保持全屏位置与大小，结束后淡出到同图高斯背景，不再缩入顶栏。8 个页面根共用 SSR 背景 partial。
- 外观图库支持指定图片、分类、跟随开屏、纯色，保存至现有账号偏好字段。服务端图库白名单、context token 和版本 CAS 保留；无数据库结构变更。
- 图库请求在失败、无效响应、超时后允许重试；预模糊图缺失才验证原图并回退单层高斯。两张图均缺失时保留当前背景，旧异步结果不能覆盖新选择。
- 材质令牌、材质边界、场景明暗色对和控件状态集中在共享 LQ 模块。面板不再各自重复绘制背景贴片；师生登录不再叠加额外 80% 黑色遮罩。
- 登录 A/B 能力档都按照片明暗选择正文、次要文字和输入色对，关闭玻璃与高对比退路保留。备案区也使用共享材质。
- 按下、选中、展开、菜单键盘聚焦时前景与背景同步切换；加载保留文字与 spinner，禁用状态不再借透明文字实现。Jinja、原生和 React 共享该规则。
- 顶栏外观菜单接入共享浮层管理，保留原生 details 退路；脱离顶栏过滤上下文后才能实际模糊底下的页面内容。

具体参数与扩展接口见 `lq-material-system-2026-09-23.md`，背景生命周期见 `lq-background-lifecycle-2026-09-23.md`。
