# 首页筛选与 3D 课表改进

## 行为与信息来源

- 搜索栏在上，筛选区在下；筛选项根据可用宽度换行，左边界一致。
- 教师无显式筛选时默认近期活跃；首次访问使用当前学期、3D 课表。之后尊重已保存的视图与学期；显式 `filter=all` 在刷新后保留。学生保留原列表默认，并增加 3D 入口。
- 学生视图顶部常显“仅显示本平台课程，所有课程请查看教务系统”。新增只读接口 `/api/dashboard/course-schedule/overview`，复用首页有效学生、主班与合班授权、平台学期及真实课次。不会读取教师的完整教务课表，也不会同步、建表或修改课次。
- 学生调课使用实际日期；已取消课次不显示。缺失日期或节次的课次不虚构时间，显示说明并保留课堂入口。自定义学期可从课表内部选择。
- 教师沿用原课表接口；课表中已绑定课堂的课程随搜索、状态与课堂学期筛选。未绑定课堂的排课在“全部”下保留，仍可创建课堂。
- 顶部学期支持第一、第二、第三学期。教师原始自由文本学期尚不属于原教务接口的学年学期合同，显示明确的列表替代说明，避免静默加载另一学期。
- 多次切换学期取消旧请求，迟到响应无法覆盖新选择；重试使用失败时选中的学期；课表内部选中的自定义学期在搜索后保持。

## 课程详情布局

复用 `course_schedule_deck.js`，首页和课时统计页共用。同一个课程链接以稳定格子为锚点，按自然内容测量宽高；短卡维持紧凑，长班级名称换行。位置限制在放大课表内部，边缘向内避让，避免外框裁切。只有内容实际超过可用高度才内部滚动；滚动详情不会切换教学周。

键盘焦点可展开，Escape 先关闭课程详情、再关闭整张课表。触屏首点查看课程详情，第二点进入课堂；链接的正常键盘与组合键行为保留。

## 验收

1. 1440、1024、390 像素宽下搜索与筛选左边界相差小于 2 像素，筛选位于搜索下方，页面无横向溢出。
2. 全新教师访问选中近期活跃与 3D，存在当前学期时选中它；主动选择列表／全部学期后刷新保持。
3. 点击“全部”后 URL 有 `filter=all`，刷新仍为全部。
4. 学生入口调用学生接口，灰色说明常显；每个课程链接指向其授权课堂；搜索会改变课表内真实课程。
5. 非学生、停用／删除学生被拒绝；他班课程、他人学期、撤销的合班成员关系不能读取。
6. 21 个授权课堂仍为 4 次批量 SELECT；SQLite `query_only` 下接口成功。无 schema 或持久化数据修改。
7. 快速切换学期、旧响应迟到、失败重试、自定义学期搜索均不串数据。
8. 短文本、8 班名称、极长文本、周日边缘、无课堂链接、键盘焦点和 390 像素触屏均可查看完整详情；仅必要时出现内滚动。

自动化入口：`tests/e2e/specs/dashboard-schedule.spec.ts`（真实隔离 HTTP）、`tests/e2e/components/playwright.config.ts`（独立课表组件）、`tests/test_student_course_schedule.py`（授权、数据合同与查询预算）。

## 发布与可逆性

不迁移数据库，不改运行目录或登录／答题存储。合并 dev 到 main 后回到 dev，两个分支原子推送同一提交。从干净工作树打包，排除工作区现有图片和证书备份；先执行规范部署脚本 DryRun。新检查点保留旧镜像、代码、运行文件和数据库备份，隔离恢复验证后发布。

发布后核对源文件哈希、静态资源、缓存版本、容器健康、数据库结构及临发布前的关键记录。回滚恢复代码和旧镜像，保留新提交的数据；不会自动用旧数据库覆盖正常业务写入。实际发布结果记录在本次独立 release artifacts 中。
