# 空闲教室查询与 3D 编辑器修复

## 故障与边界

2026-10-08，教室查询页按 B310 搜索连续返回 HTTP 502。线上只读诊断确认：共享教学场地模糊查询在读取推荐目标时使用 `CHAR(9)`，PostgreSQL 在解析该 SQL 时失败，尚未发起教务空闲查询。直接只读访问教务同一条件可正常登录并得到 HTTP 200 JSON。

修复范围包含教室查询页与 3D 课表编辑器共用的教务查询服务、候选分页、占用结论和请求生命周期。保留教学场地列表、同类型推荐、选课、草稿、保存、取消、调课审批、授权和已有 LQ 组件；不修改数据库结构或已有课次数据。

## 查询合同

- SQL 用绑定参数移除制表符，兼容 PostgreSQL 和 SQLite；保留普通空格、全角空格、多词模糊查询和教师所属学校范围。
- 显式空类别表示全部类别，不再默认排除实验室等场地。完整验证周次、星期、节次及位图，重复选择不产生进位；异常响应不能当成成功的空列表。
- 编辑器候选按页读取，后续页可继续选择。原教室占用独立按可见场地标识、实际校区和完整目标时段核实；不因教室未出现在当前候选页或筛选结果中就判为占用。缺少可靠身份或目标查询失败时保持待核实。
- 整组时段查询为空闲，可确认组内各节空闲；整组不可用只证明至少一节占用。组合占用证据不再扩张成每节均被占用，前后端按相同的完整组合判断。
- 切换学期、校区、时段、课次或教室后，旧异步响应不能覆盖当前结果。失败会清除旧的空闲结果；加载后续页失败可重试并保留已加载候选。结果分页复用 LQ Pager，按钮沿用 LQ Button。
