# 液态玻璃模板自适应改造（2026-10-24）

用户反馈：部分按钮打开的临时浮窗没有磨砂（内容与背景混在一起）、完全不透明或位置漂移；部分板块内边距贴边或没有；板块之间没有外边距；深色背景下文字不可读。要求改进液态玻璃模板，让全平台的板块、按钮、文字更协调、更智能。

本轮不逐页修补：先用新探针在隔离合成环境里批量测出问题，按根因归成模板层的六类，再在共享层统一修，最后回到探针复测。

## 根因与模板改动

| 现象（截图） | 根因 | 模板层改动 | 位置 |
|---|---|---|---|
| 私信表情面板没磨砂、底下文字透出；外观面板同类 | raised 浮层挂在面板内部，被"嵌套材质禁止模糊"守卫误伤 | **浮动层规则**：最外层 raised、以及弹窗里的 `data-lq-presence` 临时浮层一律保留磨砂并压过嵌套守卫；减少透明度/强制颜色/打印仍关闭 | `lq/components/material-boundaries.css` |
| 反馈弹窗表情面板跑到标签行、被裁成一条 | 选择器固定"锚点上方 100%"，反馈弹窗的锚点在输入框下方且处在可滚动弹窗里 | **表情选择器智能定位**：以触发按钮为基准，测量最近裁剪祖先（或视口）里的可用空间，自动上/下翻转、限高、横向夹在可视区；锚点经 `:has(> .emoji-picker)` 自动成为定位盒 | `static/js/emoji_picker.js`、`lq/components/emoji-picker.css` |
| 修炼卡、课堂活动面板"框套框"、内容贴边 | 作者把内层设计成扁平分组（`background: transparent; padding: 0`），但共享 Surface 声明用 `!important` 把底色铺了回来 | **Surface 嵌入参数** `data-lq-surface="embedded"`：宿主里的分组不铺底、不描边、不成为模糊宿主；修炼卡加 `embedded` 参数 | `lq/components/declarative.css`、`partials/cultivation_card.html` |
| 暗色外观配亮照片：灰面板白字看不清（截图 6–8、12） | 玻璃填充与外观配对（暗 = 深色 .50），叠在亮照片上只剩中灰，白字约 3.9:1、次要字约 2.3:1 | **场景自适应浓度**：外观与页面场景色调相反时，各级填充自动调浓到 .62–.78，暗外观次要墨色提亮一档 | `lq/pages/page-material.css` |
| 分区标题、列表头、计数行直接压在照片上看不清 | 不在任何面板里的文字读随外观翻转的墨色 | **场景墨色** `--lq-scene-ink/-muted/-halo` 与 `.lq-on-scene`：按页面场景色调取墨色并加反向光晕；个人中心分区标题、班级/课堂列表头、学习路径计数行改用它 | `lq/pages/page-material.css`、`profile.css`、`growth.css`、`ui-system.src.css` |
| 修为弹窗白头白字、签名可见范围白框、全站暗色下的白卡片浅字 | 遗留 CSS 与模板内联样式里写死的浅色底（含 `--ls-c-*` 调色板常量），文字却随外观翻转 | **自适应浅色底迁移工具**：`light-dark(原值, 同色相深色玻璃)`，亮色外观逐像素不变，旧浏览器回退原值；只为亮色写的语义色文字同样转成自适应；内容槽（试卷/预览/签名图/二维码/色板/画布/打印/登录页）排除；幂等 | `tools/ui/adaptive_light_fills.py`（三遍共改写 1426 处声明） |

其他共享修复：

- **空关闭按钮**：五处 `.btn-close` 迁到玻璃按钮后成了空胶囊，共享按钮层为空的 `.lq-btn.btn-close` 画统一叉号。
- **嵌套徽标**：放在已选中/主色按钮或已按下芯片里的 Badge 跟随宿主墨色（`currentColor` 18% 底）。
- **提醒条**：个人中心邮箱提醒改用共享 Alert（语义淡色叠在不透明底上）。
- **签名页**：内联私有调色板迁成 `lq/pages/profile-signatures.css`，全部改用配对令牌；签名图片格保留白纸。
- **成长页外壳**：作用域属性挂在外壳自身，后代选择器匹配不到，外壳一直是 block，导致页头与下一块贴在一起；改为两种写法都命中。
- **课堂计数与教务标签**：`--gray-900` 底配写死白字、青字压青底，改为语义色调配对。
- **新教师引导弹窗**：raised 底配写死的 `#333`，改为材质墨色。

## 限制

- `style=""` 内联属性与 JS 拼出的行内样式不在迁移工具范围内，需探针发现后单独处理。
- `light-dark()` 需要 Chrome 123 / Safari 17.5 / Firefox 120 以上；更旧浏览器回退到改写前的亮色值（与以前行为一致）。
- 场景色调取背景图中央横带的平均亮度，照片局部明暗差异大时仍可能出现个别低对比区域；光晕与提浓用于兜底，不保证每个像素。
