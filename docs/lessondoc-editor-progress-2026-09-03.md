# LessonDoc 编辑器续建进度

本记录追踪实际代码与验收，不替代原设计和审计文档。E0-R 的浏览器证据、E1 的后端测试和 E2—E6 的产品验收是不同阶段，不能互相代替。

## 已落地

### 模型与运行时

E0-R 的净化、幂等 CSS、稳定 ID、引用检查、输入预算、交互生命周期、固定编辑坐标和首页长页桥接已实现。真实浏览器检查最终 24 项全部通过，连续增量替换扩大为 100 次；7 个运行时资产的示例与分发版本逐字节一致。

### 保存与写入者

- 内容真源保留为 course.json 与课次 HTML 内嵌 JSON。新增历史表、独立幂等回执表、元素模板表；不改旧表列。
- 每个 pack 的提交段串行，AI、Git 网络等待及媒体接收不占包写锁。文件 hash 是文档版本，SQL 条件更新检查旧 hash。
- 历史、文件引用、首页及缓存、课次状态、必要的引擎刷新同事务提交。失败回滚，正文没有变化时不增加正文历史。
- 整课/单页 AI、编辑保存、恢复、管理设置、导入、Git、通用源码编辑已接入。管理端标题同时更新正文与首页；排除仍由显式管理操作控制。
- Git 对已登记文档先验证模型，再走统一保存；原始文本回写跳过受保护的正文和引擎文件。课程首页仍从 course.json 派生。更改登记课次结构或删除其文件时明确拒绝，不悄悄留下断开的课堂绑定。
- 通用源码编辑新增版本字段，返回实际规范化后的源码。原有其他文本编辑与编码流程保留，原有 AI 材料优化不修改 LessonDoc 文件真源。

### 素材、模板与权限

- 上传 API 接收原始 File 请求体，参数是 filename、lesson_no；图片/音频/视频限额为 8/20/100 MiB。接收过程中限制字节；图片核验格式和解码，最高 3600 万像素；SVG 先净化。采用原子文件落盘。
- 模板资源保存在教师材料库的“学习文档元素素材”目录，为普通材料引用；跨包实例在目标包内拥有独立文件引用。底层字节按 hash 去重，不依赖原包继续存在。
- 删除模板保留素材库中的素材及已插入实例。素材整理继续使用材料库原有操作。
- 模板去掉课次导航和子树外动作；插入时仅重新分配块 ID，图示节点和 SVG 内部标识保持其局部语义。HTML、背景、视频封面等资源路径统一解析、搬运。
- 编辑 API、素材 API、模板 API 均按教师及 owner 隔离。可信预览使用平台运行时、同源资源授权和 CSP；源码不执行来自上传包的壳脚本。
- 恢复历史前检查资源引用；缺失资源返回诊断。现阶段历史保障正文，不额外承诺恢复已经删除的媒体字节。

## 当前 API

统一前缀 /api/lessondoc/editor，成功响应为 {status:"ok", result:...}，业务错误包含 error.code/message。

| 路径 | 方法 | 用途 |
|---|---|---|
| /editability/{material_id} | GET | 解析真实编辑目标，可带包内 path |
| /packs/{id}/document?lesson_no=N | GET、PUT | 加载与保存，0 表示首页 |
| /packs/{id}/validate?lesson_no=N | POST | 只校验候选模型 |
| /packs/{id}/ai-proposal?lesson_no=N | POST | 生成候选正文，教师确认后再保存 |
| /legacy-context/{material_id} | GET | 旧包转换上下文及可用课程 |
| /packs/{id}/revisions | GET | 最近 20 条历史元数据 |
| /packs/{id}/revisions/{rid} | GET | 历史正文与缺素材诊断 |
| /packs/{id}/revisions/{rid}/restore | POST | 按当前基线恢复 |
| /packs/{id}/media | GET、POST | 素材分页及原始请求体上传 |
| /custom-elements | GET、POST | 教师模板列表及保存 |
| /custom-elements/{id} | PUT、DELETE | 改名或删除 |
| /custom-elements/{id}/insert | POST | 向目标包准备独立实例及素材引用 |
| /packs/{id}/copy-element | POST | 跨包复制候选子树并重写资源 |

可信预览为 /materials/lessondoc-editor/{pack_id}/preview?lesson=N。可视化页面已实装为 /materials/lessondoc-editor/{pack_id}?lesson=N，带 owner 检查、受限返回路径和稳定页 ID 深链；材料页、阅读壳及向导入口已接入。

通用源码 API 保持 /api/materials/{material_id}/content：GET 的 material 增加 revision/source_revision；PUT 增加同名字段及 operation_id。LessonDoc 正文要求完整基线，其他文本兼容旧客户端，同时使用条件文件更新。

## E2—E6 已落地能力

- 三栏编辑页面、21 类元素属性、命令 store、100 步/24 MiB 有界撤销历史、4.5 秒自动保存、10 秒本地草稿、规范化结果三方合并、重复请求幂等、版本冲突暂停与处理。所有异步预检在应用前复核用户修改，防止迟到结果覆盖新输入。
- 固定 1280×720 画布；单页增量替换；手势期间只修改预览，松手一个命令；框选、多选、拖动、旋转、等比缩放、对齐、分布、两层组合及拆组。多选移动在第一个合法边界整体停止，粘贴按旋转后的整体包围盒调整。
- 元素面板支持点击及原生拖放插入。流式元素支持同区排序、跨列/网格区域拖动，以及“移动至”选择器，可移入空列；首页元素可在课程说明和标签页之间移动。
- 属性面板覆盖文字、表格、测验选项/答案、代码执行轨迹、图示、局部样式、背景、动作和全局元素。代码轨迹重排自动重映射引用，拒绝引用尚未出现的源码行。删除元素清理相应动作；试播结束恢复模型定义状态。
- 页面新增、删除、复制、排序、版式转换与 JSON 编辑。HTML/CSS 先经服务端净化再预览。整页转换明确提示静态化的交互损失，保留标题/背景/全局对象；自然尺寸保持缩放比例。不能将播放器、隐藏状态或执行过程伪称为无损转换。
- 素材上传/选择、跨包复制、模板保存/改名/删除/插入与普通材料引用闭环。系统剪贴板写入失败时不剪掉原对象。
- 首页展示信息、简介、阶段分组、卡片圆角、渐变、区块标题/顺序/显隐、导图深度、补充标签及正文。阶段解析与原向导共用，支持中文符号；无效行明确报错。
- 新 AI 只返回候选，模型版本变化时标记过期；元素润色只允许内容字段，服务端保持 ID、类型、位置、外观和动作。教师通过真实运行时切换预览原稿/候选稿，并可展开前后 JSON、下载候选；确认后进入同一命令与保存流程。提示输入复用共享提示词池，关闭记录选项后不记录。原向导任务生成保留后台队列机制。
- 阅读壳通过实际 iframe 路径解析编辑目标，并携带稳定页 ID；文章模式的 AI 明确要求先切换幻灯片。首页、嵌套文件、材料卡片及向导每课均有对应入口。白板及学生学习心跳保留。
- 旧包预检、损失告警、创建新包与可选课堂绑定接通。按旧入口真实相对目录解析并复制媒体；逐课保存失败时显示实际就绪数，原包和旧绑定不自动改写。
- `LESSONDOC_EDITOR_ENABLED=false` 暂停可视化页面与新增编辑 API 写入，读接口/预览及原有流程保留。回滚时须保留已发布模型的运行时和校验能力；不可直接换回不识别新字段的旧引擎。
- 损坏正文不会退化成空稿覆盖；加载失败时可检查历史、下载恢复稿并按当前真实文件版本恢复。
