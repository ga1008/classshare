# AI 助手 Markdown 渲染修复

## 原因与范围

课件 HTML 预览使用 `material_render_shell.html`，继承的 `base.html` 不包含 Markdown 资源。该页只加载了 AI 聊天和工作区组件，缺少 marked 与 MarkdownRuntime，导致聊天进入安全纯文本降级分支，标题、粗体和表格标记原样显示。

同时检查了普通页面、课堂动态模块加载、材料查看器、作业和考试页面的依赖，以及历史消息、实时流式回复、完成和错误收尾、思考过程、Agent 产物的渲染链路。

## 修复

- 课件预览在聊天组件前加载既有 Markdown 公共资源，复用本地 marked、兼容补丁与 HTML 清理器。
- 聊天与 Agent 产物共用 `renderAIChatMarkdown`，显式导出到 window，兼容经典脚本和课堂动态 import。
- 保留模型原始 Markdown 语义，仅归一 CRLF。移除会改写行内代码、URL、围栏代码及空行的正则“修复”；首行缩进代码不再因 trim 丢失。非标准的 `#标题`、全角星号等按解析器原有规则显示，不猜测或改写内容。
- HTML 清理后只移动仍存活的节点，避免未知外层标签将已移除的 script/iframe 重新插入，并保留其中合法的嵌套内容。
- 聊天与 Agent 表格支持列对齐和局部横向滚动，宽表格不撑开手机弹窗。更新样式构建产物及缓存版本。

## 数据与运行边界

本次仅改前端、模板和文档，没有数据库结构、权限、聊天协议或持久化格式变更。历史原文不改写，复制 Markdown 使用原始消息，复制代码使用解析后的代码文本；思考过程仍按原有折叠纯文本方式展示。依赖缺失或解析异常时继续安全降级为可读文本，解析器恢复后新的渲染正常。验证使用固定回复及网络 fixture，不调用付费模型。

## 验证与发布

浏览器回归见 `tests/e2e/components/ai-chat-markdown.spec.ts`，覆盖截图样例、流式/历史一致性、错误中断、复制、代码保真、恶意 HTML、依赖异常、动态模块入口、Agent 产物以及桌面/手机布局。

部署从干净工作树执行，通过现有原生 PostgreSQL 报告、匹配备份及迁移源码哈希门禁，再执行 DryRun、停写备份和正式发布。实验备份仅用于验证，不恢复到生产库；发布脚本保护生产数据目录和浏览器业务存储。线上检查与最终发布编号另记于 `ai-markdown-production-release-2026-09-17.json`。
